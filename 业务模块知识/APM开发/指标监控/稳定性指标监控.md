# 稳定性指标监控

## 1. 稳定性监控概述

### 1.1 稳定性指标分类

**Android应用稳定性监控主要关注以下三类问题：**

```
稳定性问题分类
├── ANR（Application Not Responding）
│   ├── 主线程阻塞超时
│   ├── 广播接收器超时
│   └── 服务启动超时
├── Java异常（JE - Java Exception）
│   ├── 未捕获异常
│   ├── 空指针异常
│   └── 运行时异常
└── Native异常（NE - Native Exception）
    ├── 信号异常（SIGSEGV, SIGABRT等）
    ├── 内存访问异常
    └── 栈溢出异常
```

### 1.2 监控价值与收益

**稳定性监控的核心价值：**
- **用户体验提升**：减少应用崩溃和卡顿
- **业务连续性保障**：确保核心功能可用性
- **问题快速定位**：缩短故障排查时间
- **质量度量标准**：为版本发布提供数据支撑

## 2. ANR监控与插桩

### 2.1 ANR监控原理

ANR监控通过检测主线程消息处理超时来实现。Android系统在以下场景会触发ANR：

- **主线程**：5秒内未完成当前消息处理
- **广播接收器**：10秒内未完成onReceive()方法
- **服务**：20秒内未完成onStartCommand()或onCreate()

### 2.2 ANR监控插桩点

#### 2.2.1 主线程监控插桩

```java
// ANR监控核心实现
public class ANRMonitor {
    
    private static final int ANR_THRESHOLD = 5000; // 5秒
    private Handler mainHandler;
    private volatile long lastTickTime;
    private volatile boolean anrDetected = false;
    
    public ANRMonitor() {
        this.mainHandler = new Handler(Looper.getMainLooper());
        startMonitoring();
    }
    
    private void startMonitoring() {
        // 定时检测主线程状态
        mainHandler.post(new Runnable() {
            @Override
            public void run() {
                lastTickTime = SystemClock.uptimeMillis();
                anrDetected = false;
                
                // 定期检查
                mainHandler.postDelayed(this, 1000);
            }
        });
        
        // 监控线程
        new Thread(new Runnable() {
            @Override
            public void run() {
                while (!Thread.currentThread().isInterrupted()) {
                    try {
                        Thread.sleep(2000);
                        checkANR();
                    } catch (InterruptedException e) {
                        break;
                    }
                }
            }
        }, "ANR-Monitor").start();
    }
    
    private void checkANR() {
        long currentTime = SystemClock.uptimeMillis();
        long timeDiff = currentTime - lastTickTime;
        
        if (timeDiff > ANR_THRESHOLD && !anrDetected) {
            anrDetected = true;
            
            // 收集ANR信息
            reportANR(timeDiff, getMainThreadStackTrace());
        }
    }
    
    private StackTraceElement[] getMainThreadStackTrace() {
        // 获取主线程堆栈
        Map<Thread, StackTraceElement[]> allStackTraces = Thread.getAllStackTraces();
        for (Thread thread : allStackTraces.keySet()) {
            if (thread.getName().equals("main")) {
                return allStackTraces.get(thread);
            }
        }
        return new StackTraceElement[0];
    }
    
    private void reportANR(long blockTime, StackTraceElement[] stackTrace) {
        // 上报ANR信息到APM系统
        ANREvent event = new ANREvent();
        event.blockTime = blockTime;
        event.stackTrace = stackTrace;
        event.timestamp = System.currentTimeMillis();
        event.processName = getProcessName();
        
        APMReporter.reportANR(event);
        
        Log.e("ANRMonitor", "ANR detected! Block time: " + blockTime + "ms");
        Log.e("ANRMonitor", "Stack trace: " + Arrays.toString(stackTrace));
    }
}

// ANR事件数据结构
public class ANREvent {
    public long blockTime;           // 阻塞时间
    public StackTraceElement[] stackTrace; // 堆栈信息
    public long timestamp;           // 时间戳
    public String processName;       // 进程名
    public String activityName;      // 当前Activity
    public Map<String, Object> extraInfo; // 额外信息
}
```

#### 2.2.2 广播接收器ANR监控

```java
// 广播ANR监控
public class BroadcastANRMonitor {
    
    private static final int BROADCAST_ANR_THRESHOLD = 10000; // 10秒
    private Map<String, Long> broadcastStartTimes = new ConcurrentHashMap<>();
    
    public void onBroadcastReceiveStart(String action) {
        broadcastStartTimes.put(action, SystemClock.uptimeMillis());
    }
    
    public void onBroadcastReceiveEnd(String action) {
        Long startTime = broadcastStartTimes.remove(action);
        if (startTime != null) {
            long duration = SystemClock.uptimeMillis() - startTime;
            if (duration > BROADCAST_ANR_THRESHOLD) {
                reportBroadcastANR(action, duration);
            }
        }
    }
    
    private void reportBroadcastANR(String action, long duration) {
        // 上报广播ANR
        Log.w("BroadcastANRMonitor", "Broadcast ANR: " + action + ", duration: " + duration + "ms");
    }
}

// 使用示例：在广播接收器中插入监控
public class MonitoredBroadcastReceiver extends BroadcastReceiver {
    
    private BroadcastANRMonitor monitor = new BroadcastANRMonitor();
    
    @Override
    public void onReceive(Context context, Intent intent) {
        String action = intent.getAction();
        monitor.onBroadcastReceiveStart(action);
        
        try {
            // 实际业务逻辑
            handleBroadcast(context, intent);
        } finally {
            monitor.onBroadcastReceiveEnd(action);
        }
    }
    
    private void handleBroadcast(Context context, Intent intent) {
        // 广播处理逻辑
    }
}
```

**问题场景：**
某电商应用在商品详情页频繁出现ANR，特别是在网络加载图片和渲染复杂UI时。

**插桩方案：**

```java
public class ProductDetailANRMonitor {
    
    private static final String TAG = "ProductDetailANR";
    
    public static void monitorImageLoading() {
        // Hook图片加载库的异步任务
        HookUtils.hookAsyncTask(new HookUtils.AsyncTaskHook() {
            @Override
            public void onPreExecute(String taskName) {
                Log.d(TAG, "Image loading started: " + taskName);
            }
            
            @Override
            public void onPostExecute(String taskName, long duration) {
                if (duration > 2000) { // 2秒阈值
                    Log.w(TAG, "Slow image loading: " + taskName + ", time: " + duration + "ms");
                    reportSlowImageLoading(taskName, duration);
                }
            }
        });
    }
    
    public static void monitorUIThreadOperations() {
        // 监控主线程的耗时操作
        Handler mainHandler = new Handler(Looper.getMainLooper());
        
        // 替换主线程的MessageQueue
        HookUtils.hookMainThreadMessageQueue(new HookUtils.MessageQueueHook() {
            @Override
            public void onMessageStart(Message msg) {
                msg.obj = SystemClock.uptimeMillis(); // 记录开始时间
            }
            
            @Override
            public void onMessageEnd(Message msg) {
                Long startTime = (Long) msg.obj;
                if (startTime != null) {
                    long duration = SystemClock.uptimeMillis() - startTime;
                    if (duration > 100) { // 100ms阈值
                        Log.w(TAG, "Slow UI operation: " + msg.what + ", time: " + duration + "ms");
                    }
                }
            }
        });
    }
}
```

## 3. Java异常监控

### 3.1 Java异常监控原理

通过设置全局的未捕获异常处理器，捕获应用崩溃时的异常信息。

### 3.2 Java异常监控插桩

```java
// 全局异常监控
public class JavaExceptionMonitor {
    
    private static JavaExceptionMonitor instance;
    private Thread.UncaughtExceptionHandler defaultHandler;
    
    public static void init() {
        if (instance == null) {
            instance = new JavaExceptionMonitor();
        }
    }
    
    private JavaExceptionMonitor() {
        // 保存系统默认的异常处理器
        defaultHandler = Thread.getDefaultUncaughtExceptionHandler();
        
        // 设置自定义异常处理器
        Thread.setDefaultUncaughtExceptionHandler(new Thread.UncaughtExceptionHandler() {
            @Override
            public void uncaughtException(Thread thread, Throwable throwable) {
                // 记录异常信息
                reportJavaException(thread, throwable);
                
                // 调用系统默认处理器（会终止进程）
                if (defaultHandler != null) {
                    defaultHandler.uncaughtException(thread, throwable);
                }
            }
        });
    }
    
    private void reportJavaException(Thread thread, Throwable throwable) {
        JavaExceptionEvent event = new JavaExceptionEvent();
        event.threadName = thread.getName();
        event.exceptionType = throwable.getClass().getName();
        event.exceptionMessage = throwable.getMessage();
        event.stackTrace = throwable.getStackTrace();
        event.timestamp = System.currentTimeMillis();
        
        // 收集额外信息
        event.deviceInfo = collectDeviceInfo();
        event.appInfo = collectAppInfo();
        event.userInfo = collectUserInfo();
        
        // 上报到APM系统
        APMReporter.reportJavaException(event);
        
        // 本地保存崩溃日志
        saveCrashLogLocally(event);
    }
    
    // 关键业务异常监控
    public static void monitorBusinessException(String businessType, Runnable businessLogic) {
        try {
            businessLogic.run();
        } catch (Exception e) {
            // 业务异常监控
            reportBusinessException(businessType, e);
            throw e;
        }
    }
    
    private static void reportBusinessException(String businessType, Exception e) {
        BusinessExceptionEvent event = new BusinessExceptionEvent();
        event.businessType = businessType;
        event.exception = e;
        event.timestamp = System.currentTimeMillis();
        
        APMReporter.reportBusinessException(event);
    }
}

// 使用示例：在Application中初始化
public class MyApplication extends Application {
    
    @Override
    public void onCreate() {
        super.onCreate();
        
        // 初始化异常监控
        JavaExceptionMonitor.init();
        
        // 监控关键业务
        monitorKeyBusiness();
    }
    
    private void monitorKeyBusiness() {
        // 监控支付业务
        JavaExceptionMonitor.monitorBusinessException("payment", new Runnable() {
            @Override
            public void run() {
                // 支付业务逻辑
                processPayment();
            }
        });
    }
}
```

### 3.3 实战案例：金融应用异常监控

```java
// 交易流程异常监控
public class TransactionMonitor {
    
    public static void monitorTransaction(String transactionId, TransactionTask task) {
        long startTime = System.currentTimeMillis();
        
        try {
            // 执行交易任务
            task.execute();
            
            long duration = System.currentTimeMillis() - startTime;
            
            // 记录成功交易
            recordTransactionSuccess(transactionId, duration);
            
        } catch (BusinessException e) {
            // 业务异常
            recordTransactionFailure(transactionId, e, "business_error");
            throw e;
            
        } catch (NetworkException e) {
            // 网络异常
            recordTransactionFailure(transactionId, e, "network_error");
            throw e;
            
        } catch (Exception e) {
            // 未知异常
            recordTransactionFailure(transactionId, e, "unknown_error");
            throw e;
        }
    }
    
    private static void recordTransactionSuccess(String transactionId, long duration) {
        TransactionEvent event = new TransactionEvent();
        event.transactionId = transactionId;
        event.status = "success";
        event.duration = duration;
        event.timestamp = System.currentTimeMillis();
        
        APMReporter.reportTransaction(event);
    }
    
    private static void recordTransactionFailure(String transactionId, Exception e, String errorType) {
        TransactionEvent event = new TransactionEvent();
        event.transactionId = transactionId;
        event.status = "failure";
        event.errorType = errorType;
        event.errorMessage = e.getMessage();
        event.timestamp = System.currentTimeMillis();
        
        APMReporter.reportTransaction(event);
    }
}
```

## 4. Native异常监控

### 4.1 Native异常监控原理

Native异常监控通过信号处理机制捕获C/C++层的崩溃信号。

### 4.2 Native异常监控插桩

```c
// Native异常监控实现
#include <signal.h>
#include <unistd.h>
#include <android/log.h>
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>

#define TAG "NativeExceptionMonitor"

// 保存原始信号处理器
static struct sigaction original_sigaction[32];

// 信号处理函数
void signal_handler(int signal, siginfo_t* info, void* context) {
    // 记录异常信息
    log_native_exception(signal, info, context);
    
    // 调用原始信号处理器
    if (original_sigaction[signal].sa_handler != NULL && 
        original_sigaction[signal].sa_handler != SIG_DFL && 
        original_sigaction[signal].sa_handler != SIG_IGN) {
        
        if (original_sigaction[signal].sa_flags & SA_SIGINFO) {
            original_sigaction[signal].sa_sigaction(signal, info, context);
        } else {
            original_sigaction[signal].sa_handler(signal);
        }
    } else {
        // 默认处理：终止进程
        raise(signal);
    }
}

// 初始化Native异常监控
void init_native_exception_monitor() {
    int signals[] = {SIGSEGV, SIGABRT, SIGBUS, SIGFPE, SIGILL, SIGTRAP};
    int signal_count = sizeof(signals) / sizeof(signals[0]);
    
    struct sigaction new_sa;
    new_sa.sa_sigaction = signal_handler;
    sigemptyset(&new_sa.sa_mask);
    new_sa.sa_flags = SA_SIGINFO | SA_ONSTACK;
    
    for (int i = 0; i < signal_count; i++) {
        int signal = signals[i];
        
        // 保存原始处理器
        if (sigaction(signal, NULL, &original_sigaction[signal]) == 0) {
            // 设置新的信号处理器
            sigaction(signal, &new_sa, NULL);
        }
    }
    
    __android_log_print(ANDROID_LOG_INFO, TAG, "Native exception monitor initialized");
}

// 记录Native异常信息
void log_native_exception(int signal, siginfo_t* info, void* context) {
    char log_path[256];
    snprintf(log_path, sizeof(log_path), "/data/data/com.example.app/files/native_crash_%d.log", 
             getpid());
    
    int fd = open(log_path, O_WRONLY | O_CREAT | O_APPEND, 0644);
    if (fd >= 0) {
        char buffer[1024];
        int len = snprintf(buffer, sizeof(buffer), 
                          "Native crash: signal=%d, code=%d, pid=%d, tid=%d, address=%p\n",
                          signal, info->si_code, getpid(), gettid(), info->si_addr);
        
        write(fd, buffer, len);
        
        // 记录堆栈信息
        log_backtrace(fd, context);
        
        close(fd);
    }
    
    __android_log_print(ANDROID_LOG_ERROR, TAG, 
                       "Native crash detected: signal=%d, address=%p", 
                       signal, info->si_addr);
}

// JNI接口
JNIEXPORT void JNICALL
Java_com_example_app_NativeMonitor_initNativeMonitor(JNIEnv *env, jobject thiz) {
    init_native_exception_monitor();
}
```

## 5. 稳定性监控最佳实践

### 5.1 数据采集策略

1. **分级采集**：根据异常严重程度采用不同的采集频率
2. **抽样策略**：对高频异常进行抽样，避免数据爆炸
3. **上下文信息**：收集设备信息、用户行为、网络状态等上下文

### 5.2 性能优化建议

1. **异步上报**：异常信息异步上报，避免阻塞主线程
2. **本地缓存**：网络异常时本地缓存数据，网络恢复后上报
3. **数据压缩**：对上报数据进行压缩，减少网络流量

### 5.3 隐私安全考虑

1. **数据脱敏**：对敏感信息进行脱敏处理
2. **用户授权**：获取用户同意后再收集数据
3. **合规性**：遵守相关法律法规和隐私政策

通过完善的稳定性监控体系，可以显著提升应用质量和用户体验，为业务发展提供可靠的技术保障。
