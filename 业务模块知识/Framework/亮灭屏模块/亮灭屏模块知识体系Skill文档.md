# 亮灭屏模块知识体系Skill文档

## 1. 核心知识部分

### 1.1 主要数据结构
- **PowerManagerService**：电源管理核心服务，管理设备电源状态
- **DisplayManagerService**：显示管理核心服务，管理设备显示状态
- **ThermalManagerService**：温控服务，管理设备温度控制
- **AlwaysOnDisplayService**：息屏显示服务，管理息屏显示功能
- **WakeLock**：唤醒锁，控制设备唤醒状态
- **DisplayPowerState**：显示电源状态，管理屏幕亮度和开关
- **PowerState**：设备电源状态，管理设备整体电源状态

### 1.2 设计思路
- **分层设计**：电源管理层、显示管理层、温控层、息屏显示层
- **事件驱动模型**：基于系统事件（如按键、传感器事件）触发亮灭屏操作
- **策略模式**：针对不同场景（如充电、用户交互）采用不同的亮灭屏策略
- **状态机设计**：使用状态机管理设备电源和显示状态的转换

### 1.3 线程进程模型
- **SystemServer进程**：所有核心服务（PMS、DMS等）运行在此进程
- **Binder通信**：各服务间通过Binder进行跨进程通信
- **异步处理**：耗时操作（如传感器数据处理）在独立线程中执行
- **唤醒锁机制**：确保关键操作完成前设备不会进入休眠状态

### 1.4 对外接口
- **PowerManager**：应用访问电源管理功能的主要接口
- **DisplayManager**：应用访问显示管理功能的主要接口
- **WakeLock API**：应用控制设备唤醒状态的接口
- **adb指令**：`adb shell dumpsys power`、`adb shell dumpsys display`、`adb shell am broadcast -a android.intent.action.SCREEN_OFF`

### 1.5 核心流程
- **亮屏流程**：按键/传感器触发→PMS处理→DMS控制显示→屏幕点亮
- **灭屏流程**：超时/按键触发→PMS处理→DMS控制显示→屏幕熄灭
- **息屏显示流程**：灭屏后→AON服务启动→显示特定内容
- **温度控制流程**：温度传感器检测→Thermal服务处理→调整显示亮度或设备性能

### 1.6 主要功能
- **电源状态管理**：管理设备的开机、关机、休眠、唤醒等状态
- **显示状态管理**：控制屏幕的点亮、熄灭、亮度调节等
- **温度控制**：根据设备温度调整系统性能和显示参数
- **息屏显示**：支持灭屏后显示时间、通知等信息
- **手势识别**：支持息屏手势（如双击亮屏、画字母唤醒）
- **人来亮屏**：通过传感器检测用户靠近自动亮屏

## 2. 项目经验部分

### 2.1 功能定制
- **自定义亮屏策略**：根据特定场景（如会议模式、夜间模式）定制亮屏行为
- **息屏显示个性化**：支持用户自定义息屏显示内容和样式
- **温度控制优化**：根据设备使用场景优化温度控制策略

### 2.2 交互逻辑定制
- **手势识别增强**：添加自定义息屏手势（如画图案启动应用）
- **传感器融合**：结合多种传感器数据优化亮灭屏触发条件

### 2.3 性能优化
- **亮灭屏速度优化**：减少亮灭屏过程中的延迟
- **功耗优化**：优化息屏显示和传感器检测的功耗
- **温度控制优化**：在保证性能的同时降低设备温度
