# 显存核心知识：获取指令与指标分析

## 1. 获取内存/显存的指令

### 1.1 Android系统级命令

#### 1.1.1 dumpsys命令
```bash
# 获取SurfaceFlinger显存信息
dumpsys SurfaceFlinger --display-id 0

# 获取GPU显存信息
dumpsys gfxinfo

# 获取系统内存信息（包含显存）
dumpsys meminfo

# 获取特定进程的显存使用
dumpsys meminfo <package_name>
```

#### 1.1.2 proc文件系统命令
```bash
# 查看GPU显存信息
cat /sys/kernel/debug/dri/0/amdgpu_gem_info

# 查看显存使用统计
cat /sys/kernel/debug/dri/0/amdgpu_vram_mm

# 查看GPU频率和显存频率
cat /sys/class/kgsl/kgsl-3d0/gpuclk
cat /sys/class/kgsl/kgsl-3d0/memclk
```

### 1.2 Linux系统命令

#### 1.2.1 GPU相关命令
```bash
# 使用nvidia-smi（NVIDIA GPU）
nvidia-smi

# 使用radeontop（AMD GPU）
radeontop

# 使用intel_gpu_top（Intel GPU）
intel_gpu_top
```

#### 1.2.2 内存监控命令
```bash
# 查看系统内存使用
free -h

# 查看详细内存映射
cat /proc/meminfo

# 查看进程内存映射
cat /proc/<pid>/maps
cat /proc/<pid>/smaps
```

### 1.3 Android开发工具命令

#### 1.3.1 ADB命令
```bash
# 获取GPU渲染信息
adb shell dumpsys gfxinfo <package_name> framestats

# 获取SurfaceFlinger调试信息
adb shell dumpsys SurfaceFlinger --latency <window_name>

# 获取显存分配信息
adb shell dumpsys SurfaceFlinger --dispsync
```

## 3. 指标计算原理

### 3.1 显存大小计算公式

#### 3.1.1 图形缓冲区大小计算
```
缓冲区大小 = 宽度 × 高度 × 每像素字节数 × 层数

示例：1080×2400 RGBA_8888 单层缓冲区
大小 = 1080 × 2400 × 4 × 1 = 10,368,000 字节 ≈ 9.89 MB
```

#### 3.1.2 不同像素格式的字节数
- **RGBA_8888**：4字节/像素
- **RGB_565**：2字节/像素  
- **RGBA_F16**：8字节/像素
- **YUV420**：1.5字节/像素（Y:1, U:0.25, V:0.25）

### 3.2 mmap信息获取节点

#### 3.2.1 进程内存映射信息
```bash
# 查看进程内存映射详情
cat /proc/<pid>/maps
cat /proc/<pid>/smaps

# 示例maps输出
7f8a10000000-7f8a10200000 rw-s 00000000 00:04 1234   /dev/kgsl-3d0  # GPU显存映射
7f8a10200000-7f8a10400000 rw-s 00000000 00:04 1235   /dev/ion       # ION内存映射
```

#### 3.2.2 图形设备映射信息
```bash
# GPU设备映射信息
ls -la /dev/kgsl*
ls -la /dev/ion

# 查看ION内存统计
cat /sys/kernel/debug/ion/ion_mm_heap
```

### 3.3 显存指标来源分析

#### 3.3.1 从Gralloc模块获取
- **分配大小**：通过Gralloc分配器记录
- **使用标志**：记录缓冲区的使用方式（GPU、CPU等）
- **内存类型**：区分不同类型的内存（CMA、系统、GPU等）

#### 3.3.2 从SurfaceFlinger获取
- **活跃缓冲区**：当前正在使用的图形缓冲区
- **缓冲区状态**：缓冲区的生命周期状态
- **合成信息**：缓冲区在合成过程中的使用情况

#### 3.3.3 从GPU驱动获取
- **GPU显存**：GPU专用显存的使用情况
- **显存频率**：显存工作频率和带宽
- **温度监控**：显存温度状态
