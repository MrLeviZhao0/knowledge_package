# 显存核心知识：概述与数据结构

## 1. 模块概述

显存（Graphics Memory）是Android显示系统中用于存储图形数据的专用内存区域，主要包括GPU显存和图形缓冲区内存。在Android系统中，显存管理涉及多个层次，从应用层到硬件层，共同协作完成图形数据的存储和传输。

### 1.1 核心职责
- **图形缓冲区管理**：管理应用绘制的图形缓冲区
- **内存分配与回收**：负责显存的动态分配和释放
- **性能优化**：通过内存复用、缓存策略优化显存使用
- **内存监控**：监控显存使用情况，防止内存泄漏和溢出

### 1.2 系统架构位置
```
应用层 (App) → 框架层 (Framework) → SurfaceFlinger → Gralloc → 显示驱动 → GPU/显存
```

## 3. 显存类型与层次

### 3.1 显存分类
- **GPU专用显存**：GPU专用的高速内存
- **系统共享显存**：CPU和GPU共享的内存区域
- **图形缓冲区内存**：用于存储图形数据的缓冲区

### 3.2 内存层次结构
```
L1 Cache (GPU) → L2 Cache (GPU) → GPU专用显存 → 系统共享显存 → 主内存
```

## 4. 关键性能指标

### 4.1 显存使用指标
- **已分配显存**：当前已分配的显存总量
- **峰值显存**：历史最高显存使用量
- **显存碎片率**：显存碎片化程度
- **缓冲区数量**：当前活跃的图形缓冲区数量

### 4.2 性能监控指标
- **分配延迟**：显存分配所需时间
- **传输带宽**：CPU-GPU间数据传输速率
- **缓存命中率**：显存缓存命中比例

### 5.3 APP侧监控方法

#### 5.3.1 Android API监控
```java
public class GraphicsMemoryMonitor {
    
    // 获取应用显存使用情况
    public static long getGraphicsMemoryUsage() {
        Debug.MemoryInfo memoryInfo = new Debug.MemoryInfo();
        Debug.getMemoryInfo(memoryInfo);
        return memoryInfo.getTotalGraphics();
    }
    
    // 监控Surface显存使用
    public static void monitorSurfaceMemory(Surface surface) {
        // 通过反射获取Surface内部状态
        try {
            Field producerField = surface.getClass().getDeclaredField("mProducer");
            producerField.setAccessible(true);
            Object producer = producerField.get(surface);
            
            // 获取BufferQueue状态
            monitorBufferQueueState(producer);
        } catch (Exception e) {
            Log.e("MemoryMonitor", "Failed to monitor surface memory", e);
        }
    }
    
    // 实时监控显存水位
    public static void startRealTimeMonitoring() {
        Handler handler = new Handler(Looper.getMainLooper());
        Runnable monitorRunnable = new Runnable() {
            @Override
            public void run() {
                long graphicsMemory = getGraphicsMemoryUsage();
                Log.d("MemoryMonitor", "Current graphics memory: " + graphicsMemory + " KB");
                
                // 检查内存压力
                if (graphicsMemory > WARNING_THRESHOLD) {
                    Log.w("MemoryMonitor", "Graphics memory usage is high!");
                    triggerMemoryOptimization();
                }
                
                handler.postDelayed(this, MONITOR_INTERVAL);
            }
        };
        handler.post(monitorRunnable);
    }
}
```

#### 5.3.2 Native层监控
```cpp
#include <android/trace.h>
#include <sys/system_properties.h>

class NativeMemoryMonitor {
public:
    // 监控GraphicBuffer分配
    static void monitorGraphicBufferAllocation(uint32_t width, uint32_t height, 
                                              PixelFormat format, uint64_t usage) {
        size_t estimatedSize = calculateBufferSize(width, height, format);
        
        ATrace_beginSection("GraphicBuffer_Allocation");
        ATrace_setCounter("buffer_width", width);
        ATrace_setCounter("buffer_height", height);
        ATrace_setCounter("buffer_size", estimatedSize);
        
        // 记录分配事件
        logMemoryEvent("BUFFER_ALLOC", estimatedSize);
        
        ATrace_endSection();
    }
    
    // 获取系统显存信息
    static void getSystemGraphicsMemoryInfo() {
        char prop_value[PROP_VALUE_MAX];
        
        // 获取GPU信息
        __system_property_get("ro.hardware.gpu", prop_value);
        std::string gpuModel = prop_value;
        
        // 获取显存大小
        __system_property_get("ro.config.gpu_memory_size", prop_value);
        int gpuMemorySize = atoi(prop_value);
        
        ALOGI("GPU Model: %s, Memory Size: %d MB", gpuModel.c_str(), gpuMemorySize);
    }
    
private:
    static size_t calculateBufferSize(uint32_t width, uint32_t height, PixelFormat format) {
        size_t bytesPerPixel = 4; // 默认RGBA_8888
        switch (format) {
            case HAL_PIXEL_FORMAT_RGBA_8888:
                bytesPerPixel = 4;
                break;
            case HAL_PIXEL_FORMAT_RGB_565:
                bytesPerPixel = 2;
                break;
            case HAL_PIXEL_FORMAT_RGBA_FP16:
                bytesPerPixel = 8;
                break;
            default:
                bytesPerPixel = 4;
        }
        return width * height * bytesPerPixel;
    }
    
    static void logMemoryEvent(const char* event, size_t size) {
        ALOGD("MemoryEvent: %s - Size: %zu bytes", event, size);
    }
};
```

#### 5.4.2 告警处理机制
```java
public class MemoryAlertHandler {
    
    public static void handleMemoryAlert(MemoryLevel level, long currentUsage) {
        switch (level) {
            case WARNING:
                Log.w("MemoryAlert", "Graphics memory usage is high: " + currentUsage + " MB");
                // 触发轻度优化
                triggerLightOptimization();
                break;
                
            case CRITICAL:
                Log.e("MemoryAlert", "Graphics memory usage is critical: " + currentUsage + " MB");
                // 触发重度优化
                triggerAggressiveOptimization();
                // 通知用户
                showMemoryWarningDialog();
                break;
                
            case NORMAL:
                // 正常状态，无需处理
                break;
        }
    }
    
    private static void triggerLightOptimization() {
        // 清理缓存
        BitmapCache.clear();
        // 降低非关键资源质量
        reduceNonCriticalQuality();
    }
    
    private static void triggerAggressiveOptimization() {
        // 强制垃圾回收
        System.gc();
        // 释放所有可释放资源
        releaseAllDisposableResources();
        // 大幅降低图形质量
        reduceGraphicsQualityDrastically();
    }
}
```

### 5.5 监控数据可视化

#### 5.5.1 实时监控界面
```java
public class MemoryMonitorView extends View {
    private Paint normalPaint, warningPaint, criticalPaint;
    private long currentMemory;
    private long maxMemory;
    
    public MemoryMonitorView(Context context) {
        super(context);
        initPaints();
    }
    
    @Override
    protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);
        
        float usageRatio = (float) currentMemory / maxMemory;
        int barWidth = (int) (getWidth() * usageRatio);
        
        // 根据水位选择颜色
        Paint paint = getPaintForLevel(usageRatio);
        
        // 绘制内存使用条
        canvas.drawRect(0, 0, barWidth, getHeight(), paint);
        
        // 绘制文字信息
        String text = String.format("Graphics Memory: %d/%d MB", 
                                   currentMemory / 1024 / 1024, 
                                   maxMemory / 1024 / 1024);
        canvas.drawText(text, 10, 20, normalPaint);
    }
    
    public void updateMemoryUsage(long current, long max) {
        this.currentMemory = current;
        this.maxMemory = max;
        invalidate();
    }
}
```
