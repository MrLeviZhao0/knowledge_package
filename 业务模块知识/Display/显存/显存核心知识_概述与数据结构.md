# 显存核心知识：概述与数据结构

## 1. 模块概述

显存（Graphics Memory）是Android显示系统中用于存储图形数据的专用内存区域，主要包括GPU显存和图形缓冲区内存。在Android系统中，显存管理涉及多个层次，从应用层到硬件层，共同协作完成图形数据的存储和传输。

### 1.1 核心职责
- **图形缓冲区管理**：管理应用绘制的图形缓冲区
- **内存分配与回收**：负责显存的动态分配和释放
- **性能优化**：通过内存复用、缓存策略优化显存使用
- **内存监控**：监控显存使用情况，防止内存泄漏和溢出

### 1.2 系统架构位置
```
应用层 (App) → 框架层 (Framework) → SurfaceFlinger → Gralloc → 显示驱动 → GPU/显存
```

## 3. 显存类型与层次

### 3.1 显存分类
- **GPU专用显存**：GPU专用的高速内存
- **系统共享显存**：CPU和GPU共享的内存区域
- **图形缓冲区内存**：用于存储图形数据的缓冲区

### 3.2 内存层次结构
```
L1 Cache (GPU) → L2 Cache (GPU) → GPU专用显存 → 系统共享显存 → 主内存
```

## 4. 关键性能指标

### 4.1 显存使用指标
- **已分配显存**：当前已分配的显存总量
- **峰值显存**：历史最高显存使用量
- **显存碎片率**：显存碎片化程度
- **缓冲区数量**：当前活跃的图形缓冲区数量

### 4.2 性能监控指标
- **分配延迟**：显存分配所需时间
- **传输带宽**：CPU-GPU间数据传输速率
- **缓存命中率**：显存缓存命中比例
