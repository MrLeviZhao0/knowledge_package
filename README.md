## 功能说明

这个3D可视化页面展示了Android知识库的结构和内容，具有以下功能：

- 3D交互式图形
- 节点根据层级显示不同颜色和大小
- 节点标签始终可见，不需要鼠标悬停
- 点击目录节点可展开/折叠子节点
- 点击文档节点可跳转到对应内容
- 支持视角重置、切换连线、切换标签等控制功能

## 使用说明

1. 使用鼠标拖拽旋转视角
2. 使用滚轮缩放
3. 点击节点查看详细信息
4. 使用底部控制按钮进行各种操作
