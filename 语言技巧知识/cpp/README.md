# C++语言知识库

## 概述
C++是一种高性能的系统级编程语言，支持面向对象、泛型和函数式编程范式。广泛应用于游戏开发、操作系统、嵌入式系统、高性能计算等领域。本知识库详细介绍了C++的核心特性、内存管理、模板编程、并发编程以及面试常见问题。

## 快速开始

### 安装C++编译器
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install g++ build-essential

# CentOS/RHEL
sudo yum groupinstall "Development Tools"

# macOS
xcode-select --install
```

### 第一个C++程序
```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++!" << std::endl;
    return 0;
}

// 编译和运行
// g++ -o hello hello.cpp
// ./hello
```
