## 内存管理相关问题

### 问题1: 智能指针

**问题：** 请解释C++中的智能指针，并说明unique_ptr、shared_ptr和weak_ptr的区别。

**参考答案：**
```cpp
/**
 * C++智能指针：
 * 
 * 1. unique_ptr（独占所有权）
 *    - 一个对象只能被一个unique_ptr拥有
 *    - 不支持拷贝构造和赋值，但支持移动语义
 *    - 适用于独占资源管理
 * 
 * 2. shared_ptr（共享所有权）
 *    - 多个shared_ptr可以共享同一个对象
 *    - 使用引用计数管理生命周期
 *    - 适用于共享资源管理
 * 
 * 3. weak_ptr（弱引用）
 *    - 不增加引用计数，不控制对象生命周期
 *    - 用于解决shared_ptr的循环引用问题
 *    - 需要通过lock()方法获取shared_ptr
 */

#include <memory>
#include <iostream>

// 示例：智能指针使用
class Resource {
public:
    Resource() { std::cout << "Resource created\n"; }
    ~Resource() { std::cout << "Resource destroyed\n"; }
    void use() { std::cout << "Resource used\n"; }
};

void demo_smart_pointers() {
    // unique_ptr示例
    std::unique_ptr<Resource> ptr1 = std::make_unique<Resource>();
    ptr1->use();
    
    // shared_ptr示例
    std::shared_ptr<Resource> ptr2 = std::make_shared<Resource>();
    {
        std::shared_ptr<Resource> ptr3 = ptr2; // 引用计数+1
        ptr3->use();
    } // ptr3析构，引用计数-1
    
    // weak_ptr示例
    std::weak_ptr<Resource> weak = ptr2;
    if (auto shared = weak.lock()) {
        shared->use();
    }
}
```

### 问题2: 内存泄漏

**问题：** 什么是内存泄漏？如何在C++中避免内存泄漏？

**参考答案：**
```cpp
/**
 * 内存泄漏：程序在申请内存后，无法释放已申请的内存空间
 * 
 * 避免内存泄漏的方法：
 * 
 * 1. 使用RAII（资源获取即初始化）
 *    - 在构造函数中获取资源，在析构函数中释放资源
 *    - 确保资源在任何情况下都能正确释放
 * 
 * 2. 使用智能指针
 *    - 自动管理内存生命周期
 *    - 避免手动new/delete
 * 
 * 3. 遵循所有权规则
 *    - 明确资源的所有权归属
 *    - 避免悬空指针和野指针
 * 
 * 4. 使用容器类
 *    - std::vector、std::string等自动管理内存
 */

#include <vector>
#include <memory>

// 正确示例：使用RAII和智能指针
class SafeResource {
private:
    std::unique_ptr<int[]> data;
    size_t size;
    
public:
    SafeResource(size_t n) : size(n), data(std::make_unique<int[]>(n)) {}
    // 析构函数自动释放内存
    
    int& operator[](size_t index) {
        if (index >= size) throw std::out_of_range("Index out of range");
        return data[index];
    }
};

// 错误示例：手动内存管理容易出错
void unsafe_function() {
    int* arr = new int[100];
    // 如果这里抛出异常，内存泄漏
    // delete[] arr; // 必须手动释放
}

// 正确示例：使用容器
void safe_function() {
    std::vector<int> arr(100);
    // 自动管理内存，不会泄漏
}
```

## 模板编程相关问题

### 问题3: 模板特化

**问题：** 什么是模板特化？请举例说明完全特化和偏特化。

**参考答案：**
```cpp
/**
 * 模板特化：为特定类型提供特殊实现
 * 
 * 1. 完全特化：为特定类型提供完整实现
 * 2. 偏特化：为部分类型参数提供特殊实现
 */

#include <iostream>
#include <type_traits>

// 主模板
template<typename T>
class TypeInfo {
public:
    static std::string name() {
        return "Unknown type";
    }
};

// 完全特化：为int类型
template<>
class TypeInfo<int> {
public:
    static std::string name() {
        return "int";
    }
};

// 完全特化：为double类型
template<>
class TypeInfo<double> {
public:
    static std::string name() {
        return "double";
    }
};

// 偏特化：为指针类型
template<typename T>
class TypeInfo<T*> {
public:
    static std::string name() {
        return "Pointer to " + TypeInfo<T>::name();
    }
};

// 偏特化：为引用类型
template<typename T>
class TypeInfo<T&> {
public:
    static std::string name() {
        return "Reference to " + TypeInfo<T>::name();
    }
};

void demo_template_specialization() {
    std::cout << TypeInfo<int>::name() << std::endl;        // "int"
    std::cout << TypeInfo<double>::name() << std::endl;     // "double"
    std::cout << TypeInfo<int*>::name() << std::endl;       // "Pointer to int"
    std::cout << TypeInfo<double&>::name() << std::endl;    // "Reference to double"
}
```

### 问题4: SFINAE和概念（Concepts）

**问题：** 什么是SFINAE？C++20中的概念（Concepts）如何改进模板编程？

**参考答案：**
```cpp
/**
 * SFINAE（Substitution Failure Is Not An Error）：
 * - 模板参数替换失败不是错误
 * - 编译器会尝试其他可行的模板重载
 * 
 * C++20概念（Concepts）：
 * - 提供更清晰的模板约束语法
 * - 更好的错误信息
 * - 编译时类型检查
 */

#include <iostream>
#include <concepts>
#include <type_traits>

// C++17之前的SFINAE技术
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
add_sfinae(T a, T b) {
    return a + b;
}

template<typename T>
typename std::enable_if<!std::is_integral<T>::value, T>::type
add_sfinae(T a, T b) {
    static_assert(std::is_integral<T>::value, "T must be integral");
    return T{};
}

// C++20概念（Concepts）
template<typename T>
concept Integral = std::is_integral_v<T>;

template<typename T>
concept Arithmetic = std::is_arithmetic_v<T>;

// 使用概念约束
template<Integral T>
T add_concept(T a, T b) {
    return a + b;
}

// 更复杂的约束
template<typename T>
requires Arithmetic<T> && requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
    { a - b } -> std::convertible_to<T>;
}
T advanced_add(T a, T b) {
    return a + b;
}

void demo_concepts() {
    // 使用SFINAE
    auto result1 = add_sfinae(5, 3);        // 正常编译
    // auto result2 = add_sfinae(5.0, 3.0); // 编译错误
    
    // 使用概念
    auto result3 = add_concept(5, 3);       // 正常编译
    auto result4 = advanced_add(5.0, 3.0);  // 正常编译
    
    std::cout << "SFINAE result: " << result1 << std::endl;
    std::cout << "Concept result: " << result3 << std::endl;
    std::cout << "Advanced result: " << result4 << std::endl;
}
```

## 并发编程相关问题

### 问题5: 线程同步

**问题：** C++中有哪些线程同步机制？请说明互斥锁、条件变量和原子操作的使用场景。

**参考答案：**
```cpp
/**
 * C++线程同步机制：
 * 
 * 1. 互斥锁（mutex）：保护共享资源，防止数据竞争
 * 2. 条件变量（condition_variable）：线程间通信和协调
 * 3. 原子操作（atomic）：无锁编程，高性能并发
 * 4. 读写锁（shared_mutex）：读多写少的场景
 */

#include <iostream>
#include <thread>
#include <mutex>
#include <condition_variable>
#include <atomic>
#include <vector>

class ThreadSafeCounter {
private:
    std::mutex mtx;
    int count = 0;
    std::condition_variable cv;
    
public:
    void increment() {
        std::lock_guard<std::mutex> lock(mtx);
        ++count;
        cv.notify_all(); // 通知等待的线程
    }
    
    void wait_until(int target) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [this, target] { return count >= target; });
    }
    
    int get_count() {
        std::lock_guard<std::mutex> lock(mtx);
        return count;
    }
};

// 原子操作示例
class AtomicCounter {
private:
    std::atomic<int> count{0};
    
public:
    void increment() {
        count.fetch_add(1, std::memory_order_relaxed);
    }
    
    int get_count() const {
        return count.load(std::memory_order_relaxed);
    }
};

void demo_concurrency() {
    ThreadSafeCounter counter;
    AtomicCounter atomic_counter;
    
    std::vector<std::thread> threads;
    
    // 创建多个线程同时增加计数器
    for (int i = 0; i < 10; ++i) {
        threads.emplace_back([&counter, &atomic_counter]() {
            for (int j = 0; j < 1000; ++j) {
                counter.increment();
                atomic_counter.increment();
            }
        });
    }
    
    // 等待所有线程完成
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "Thread-safe counter: " << counter.get_count() << std::endl;
    std::cout << "Atomic counter: " << atomic_counter.get_count() << std::endl;
}
```

### 问题6: 死锁避免

**问题：** 什么是死锁？如何在C++中避免死锁？

**参考答案：**
```cpp
/**
 * 死锁：多个线程互相等待对方释放资源，导致程序无法继续执行
 * 
 * 死锁产生的四个必要条件：
 * 1. 互斥条件：资源不能被共享
 * 2. 占有且等待：线程持有资源并等待其他资源
 * 3. 不可抢占：资源只能由持有者释放
 * 4. 循环等待：存在资源请求的循环链
 * 
 * 避免死锁的方法：
 * 1. 按固定顺序获取锁
 * 2. 使用std::lock同时获取多个锁
 * 3. 使用超时机制
 * 4. 避免嵌套锁
 */

#include <iostream>
#include <thread>
#include <mutex>
#include <chrono>

class DeadlockDemo {
private:
    std::mutex mtx1, mtx2;
    
public:
    // 错误示例：可能导致死锁
    void unsafe_transfer(int amount) {
        std::lock_guard<std::mutex> lock1(mtx1);
        std::this_thread::sleep_for(std::chrono::milliseconds(100));
        std::lock_guard<std::mutex> lock2(mtx2); // 可能死锁
        
        std::cout << "Transfer: " << amount << std::endl;
    }
    
    // 正确示例：按固定顺序获取锁
    void safe_transfer_fixed_order(int amount) {
        std::lock_guard<std::mutex> lock1(mtx1);
        std::lock_guard<std::mutex> lock2(mtx2);
        
        std::cout << "Safe transfer: " << amount << std::endl;
    }
    
    // 正确示例：使用std::lock同时获取锁
    void safe_transfer_std_lock(int amount) {
        std::unique_lock<std::mutex> lock1(mtx1, std::defer_lock);
        std::unique_lock<std::mutex> lock2(mtx2, std::defer_lock);
        std::lock(lock1, lock2); // 同时获取，避免死锁
        
        std::cout << "Std lock transfer: " << amount << std::endl;
    }
    
    // 正确示例：使用超时机制
    void safe_transfer_timeout(int amount) {
        std::unique_lock<std::mutex> lock1(mtx1, std::defer_lock);
        if (lock1.try_lock_for(std::chrono::milliseconds(100))) {
            std::unique_lock<std::mutex> lock2(mtx2, std::defer_lock);
            if (lock2.try_lock_for(std::chrono::milliseconds(100))) {
                std::cout << "Timeout transfer: " << amount << std::endl;
            } else {
                std::cout << "Failed to acquire lock2" << std::endl;
            }
        } else {
            std::cout << "Failed to acquire lock1" << std::endl;
        }
    }
};

void demo_deadlock_avoidance() {
    DeadlockDemo demo;
    
    // 安全的方法
    demo.safe_transfer_fixed_order(100);
    demo.safe_transfer_std_lock(200);
    demo.safe_transfer_timeout(300);
}
```

## STL容器相关问题

### 问题7: vector和list的区别

**问题：** 请比较std::vector和std::list的性能特点和适用场景。

**参考答案：**
```cpp
/**
 * std::vector vs std::list：
 * 
 * vector特点：
 * - 动态数组，连续内存存储
 * - 随机访问O(1)，插入删除O(n)
 * - 缓存友好，内存使用效率高
 * - 适用于读多写少，需要随机访问的场景
 * 
 * list特点：
 * - 双向链表，非连续内存存储
 * - 随机访问O(n)，插入删除O(1)
 * - 缓存不友好，内存使用效率低
 * - 适用于频繁插入删除，不需要随机访问的场景
 */

#include <iostream>
#include <vector>
#include <list>
#include <chrono>

void benchmark_containers() {
    const int SIZE = 100000;
    
    // vector性能测试
    std::vector<int> vec;
    auto start = std::chrono::high_resolution_clock::now();
    
    // 尾部插入
    for (int i = 0; i < SIZE; ++i) {
        vec.push_back(i);
    }
    
    // 中间插入（性能较差）
    vec.insert(vec.begin() + SIZE/2, 999);
    
    // 随机访问
    int sum = 0;
    for (int i = 0; i < SIZE; ++i) {
        sum += vec[i];
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto vec_duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    // list性能测试
    std::list<int> lst;
    start = std::chrono::high_resolution_clock::now();
    
    // 尾部插入
    for (int i = 0; i < SIZE; ++i) {
        lst.push_back(i);
    }
    
    // 中间插入（性能较好）
    auto it = lst.begin();
    std::advance(it, SIZE/2);
    lst.insert(it, 999);
    
    // 顺序访问
    sum = 0;
    for (int val : lst) {
        sum += val;
    }
    
    end = std::chrono::high_resolution_clock::now();
    auto lst_duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    std::cout << "Vector time: " << vec_duration.count() << " microseconds" << std::endl;
    std::cout << "List time: " << lst_duration.count() << " microseconds" << std::endl;
    std::cout << "Sum: " << sum << std::endl;
}

void usage_scenarios() {
    // vector适用场景：需要随机访问
    std::vector<int> scores = {85, 92, 78, 96, 88};
    
    // 快速随机访问
    std::cout << "Third score: " << scores[2] << std::endl;
    
    // 排序（vector更适合）
    std::sort(scores.begin(), scores.end());
    
    // list适用场景：频繁插入删除
    std::list<int> task_queue;
    
    // 快速插入删除
    task_queue.push_back(1);
    task_queue.push_front(2);
    task_queue.erase(std::next(task_queue.begin()));
    
    for (int task : task_queue) {
        std::cout << "Task: " << task << std::endl;
    }
}
```

### 问题8: map和unordered_map的区别

**问题：** 请比较std::map和std::unordered_map的性能特点和适用场景。

**参考答案：**
```cpp
/**
 * std::map vs std::unordered_map：
 * 
 * map特点：
 * - 红黑树实现，按键排序
 * - 查找、插入、删除都是O(log n)
 * - 有序遍历，内存使用稳定
 * - 适用于需要有序遍历或内存敏感的场景
 * 
 * unordered_map特点：
 * - 哈希表实现，无序存储
 * - 平均查找、插入、删除是O(1)，最坏O(n)
 * - 无序遍历，内存使用可能波动
 * - 适用于需要快速查找，不关心顺序的场景
 */

#include <iostream>
#include <map>
#include <unordered_map>
#include <chrono>
#include <string>

void benchmark_maps() {
    const int SIZE = 10000;
    
    // map性能测试
    std::map<int, std::string> ordered_map;
    auto start = std::chrono::high_resolution_clock::now();
    
    for (int i = 0; i < SIZE; ++i) {
        ordered_map[i] = "Value_" + std::to_string(i);
    }
    
    // 查找操作
    for (int i = 0; i < SIZE; i += 10) {
        auto it = ordered_map.find(i);
        if (it != ordered_map.end()) {
            // 找到元素
        }
    }
    
    auto end = std::chrono::high_resolution_clock::now();
    auto map_duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    // unordered_map性能测试
    std::unordered_map<int, std::string> unordered_map;
    start = std::chrono::high_resolution_clock::now();
    
    for (int i = 0; i < SIZE; ++i) {
        unordered_map[i] = "Value_" + std::to_string(i);
    }
    
    // 查找操作
    for (int i = 0; i < SIZE; i += 10) {
        auto it = unordered_map.find(i);
        if (it != unordered_map.end()) {
            // 找到元素
        }
    }
    
    end = std::chrono::high_resolution_clock::now();
    auto umap_duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    std::cout << "Map time: " << map_duration.count() << " microseconds" << std::endl;
    std::cout << "Unordered_map time: " << umap_duration.count() << " microseconds" << std::endl;
}

void usage_scenarios_maps() {
    // map适用场景：需要有序遍历
    std::map<std::string, int> student_scores = {
        {"Alice", 85},
        {"Bob", 92},
        {"Charlie", 78}
    };
    
    // 按键顺序遍历
    std::cout << "Students in order:" << std::endl;
    for (const auto& [name, score] : student_scores) {
        std::cout << name << ": " << score << std::endl;
    }
    
    // 范围查询
    auto it_low = student_scores.lower_bound("B");
    auto it_high = student_scores.upper_bound("C");
    
    std::cout << "\nStudents from B to C:" << std::endl;
    for (auto it = it_low; it != it_high; ++it) {
        std::cout << it->first << ": " << it->second << std::endl;
    }
    
    // unordered_map适用场景：快速查找
    std::unordered_map<std::string, std::string> config = {
        {"host", "localhost"},
        {"port", "8080"},
        {"database", "test_db"}
    };
    
    // 快速配置查找
    std::string key = "port";
    if (config.find(key) != config.end()) {
        std::cout << "\n" << key << " = " << config[key] << std::endl;
    }
    
    // 自定义哈希函数（高级用法）
    struct Person {
        std::string name;
        int age;
        
        bool operator==(const Person& other) const {
            return name == other.name && age == other.age;
        }
    };
    
    struct PersonHash {
        std::size_t operator()(const Person& p) const {
            return std::hash<std::string>{}(p.name) ^ 
                   (std::hash<int>{}(p.age) << 1);
        }
    };
    
    std::unordered_map<Person, std::string, PersonHash> person_map;
    person_map[{"Alice", 25}] = "Engineer";
    person_map[{"Bob", 30}] = "Manager";
}
```

## 现代C++特性相关问题

### 问题9: 移动语义

**问题：** 什么是移动语义？请说明右值引用、移动构造函数和std::move的作用。

**参考答案：**
```cpp
/**
 * 移动语义：允许资源的所有权转移，避免不必要的拷贝
 * 
 * 关键概念：
 * 1. 右值引用（T&&）：绑定到临时对象或即将销毁的对象
 * 2. 移动构造函数：从右值"窃取"资源
 * 3. std::move：将左值转换为右值引用
 * 4. 完美转发：保持参数的值类别
 */

#include <iostream>
#include <utility>
#include <vector>
#include <string>

class Resource {
private:
    int* data;
    size_t size;
    
public:
    // 普通构造函数
    Resource(size_t n) : size(n), data(new int[n]) {
        std::cout << "Resource constructed (size=" << size << ")\n";
    }
    
    // 拷贝构造函数（深拷贝）
    Resource(const Resource& other) : size(other.size), data(new int[other.size]) {
        std::copy(other.data, other.data + size, data);
        std::cout << "Resource copied (size=" << size << ")\n";
    }
    
    // 移动构造函数（资源转移）
    Resource(Resource&& other) noexcept : size(other.size), data(other.data) {
        other.data = nullptr;
        other.size = 0;
        std::cout << "Resource moved (size=" << size << ")\n";
    }
    
    // 拷贝赋值运算符
    Resource& operator=(const Resource& other) {
        if (this != &other) {
            delete[] data;
            size = other.size;
            data = new int[size];
            std::copy(other.data, other.data + size, data);
            std::cout << "Resource copy assigned\n";
        }
        return *this;
    }
    
    // 移动赋值运算符
    Resource& operator=(Resource&& other) noexcept {
        if (this != &other) {
            delete[] data;
            data = other.data;
            size = other.size;
            other.data = nullptr;
            other.size = 0;
            std::cout << "Resource move assigned\n";
        }
        return *this;
    }
    
    ~Resource() {
        delete[] data;
        std::cout << "Resource destroyed\n";
    }
};

// 完美转发示例
template<typename T>
void process(T&& arg) {
    // std::forward保持参数的值类别
    Resource res(std::forward<T>(arg));
}

void demo_move_semantics() {
    std::cout << "=== 移动语义演示 ===" << std::endl;
    
    // 创建资源
    Resource res1(100);
    
    // 拷贝构造（深拷贝）
    Resource res2 = res1;
    
    // 移动构造（资源转移）
    Resource res3 = std::move(res1);
    
    std::cout << "\n=== 在容器中使用 ===" << std::endl;
    
    std::vector<Resource> resources;
    
    // 临时对象会触发移动语义
    resources.push_back(Resource(50));
    
    // 使用std::move显式移动
    Resource temp(75);
    resources.push_back(std::move(temp));
    
    std::cout << "\n=== 完美转发演示 ===" << std::endl;
    
    // 左值传递
    Resource lvalue(25);
    process(lvalue);  // 调用拷贝构造
    
    // 右值传递
    process(Resource(25));  // 调用移动构造
    process(std::move(lvalue));  // 调用移动构造
}
```

### 问题10: Lambda表达式

**问题：** 请解释C++中的Lambda表达式，并说明捕获列表的用法。

**参考答案：**
```cpp
/**
 * Lambda表达式：匿名函数对象，简化函数式编程
 * 
 * 语法：[捕获列表](参数列表) -> 返回类型 { 函数体 }
 * 
 * 捕获列表类型：
 * 1. []：不捕获任何变量
 * 2. [=]：按值捕获所有外部变量
 * 3. [&]：按引用捕获所有外部变量
 * 4. [var]：按值捕获特定变量
 * 5. [&var]：按引用捕获特定变量
 * 6. [this]：捕获当前类的this指针
 * 7. [=, &var]：默认按值，特定变量按引用
 */

#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>

void demo_lambda_basics() {
    std::cout << "=== Lambda基础 ===" << std::endl;
    
    // 基本Lambda
    auto simple = []() { 
        std::cout << "Hello Lambda!" << std::endl; 
    };
    simple();
    
    // 带参数的Lambda
    auto add = [](int a, int b) -> int {
        return a + b;
    };
    std::cout << "5 + 3 = " << add(5, 3) << std::endl;
    
    // 自动推导返回类型
    auto multiply = [](auto a, auto b) {
        return a * b;
    };
    std::cout << "2.5 * 4 = " << multiply(2.5, 4) << std::endl;
}

void demo_capture_list() {
    std::cout << "\n=== 捕获列表 ===" << std::endl;
    
    int x = 10, y = 20;
    
    // 按值捕获
    auto capture_by_value = [x, y]() {
        std::cout << "By value: x=" << x << ", y=" << y << std::endl;
        // x = 5; // 错误：不能修改按值捕获的变量
    };
    capture_by_value();
    
    // 按引用捕获
    auto capture_by_reference = [&x, &y]() {
        std::cout << "By reference: x=" << x << ", y=" << y << std::endl;
        x = 15; // 可以修改原始变量
        y = 25;
    };
    capture_by_reference();
    std::cout << "After reference capture: x=" << x << ", y=" << y << std::endl;
    
    // 可变Lambda（允许修改按值捕获的变量）
    auto mutable_lambda = [x]() mutable {
        std::cout << "Mutable: captured x=" << x << std::endl;
        x = 100; // 可以修改副本，不影响原始变量
        std::cout << "Mutable: modified x=" << x << std::endl;
    };
    mutable_lambda();
    std::cout << "Original x after mutable: " << x << std::endl;
}

void demo_lambda_with_stl() {
    std::cout << "\n=== Lambda与STL ===" << std::endl;
    
    std::vector<int> numbers = {5, 2, 8, 1, 9, 3};
    
    // 使用Lambda排序
    std::sort(numbers.begin(), numbers.end(), [](int a, int b) {
        return a > b; // 降序排序
    });
    
    std::cout << "Sorted descending: ";
    for (int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
    
    // 使用Lambda过滤
    auto it = std::remove_if(numbers.begin(), numbers.end(), [](int n) {
        return n < 5; // 移除小于5的元素
    });
    numbers.erase(it, numbers.end());
    
    std::cout << "Filtered (>=5): ";
    for (int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
    
    // 使用Lambda转换
    std::vector<std::string> strings;
    std::transform(numbers.begin(), numbers.end(), 
                   std::back_inserter(strings), 
                   [](int n) { 
                       return "Number: " + std::to_string(n); 
                   });
    
    std::cout << "Transformed: ";
    for (const auto& s : strings) {
        std::cout << s << " ";
    }
    std::cout << std::endl;
}

class LambdaWithClass {
private:
    int data = 42;
    
public:
    void demo_this_capture() {
        std::cout << "\n=== 类中的Lambda ===" << std::endl;
        
        // 捕获this指针
        auto member_lambda = [this]() {
            std::cout << "Class data: " << data << std::endl;
            data = 100; // 可以修改成员变量
        };
        
        member_lambda();
        std::cout << "Data after lambda: " << data << std::endl;
        
        // 泛型Lambda（C++14+）
        auto generic = [](auto&& container) {
            for (auto&& item : container) {
                std::cout << item << " ";
            }
            std::cout << std::endl;
        };
        
        generic(numbers);
        generic(strings);
    }
};

int main() {
    demo_lambda_basics();
    demo_capture_list();
    demo_lambda_with_stl();
    
    LambdaWithClass obj;
    obj.demo_this_capture();
    
    return 0;
}
```
