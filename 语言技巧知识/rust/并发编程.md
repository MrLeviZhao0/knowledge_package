# Rust并发编程

## 概述
Rust的并发编程模型基于所有权系统和类型系统，能够在编译期防止数据竞争。Rust提供了线程、消息传递、共享状态等多种并发范式。

## 线程基础

### 创建线程
```rust
use std::thread;
use std::time::Duration;

fn basic_threads() {
    // 创建新线程
    let handle = thread::spawn(|| {
        for i in 1..10 {
            println!("hi number {} from the spawned thread!", i);
            thread::sleep(Duration::from_millis(1));
        }
    });
    
    // 主线程继续执行
    for i in 1..5 {
        println!("hi number {} from the main thread!", i);
        thread::sleep(Duration::from_millis(1));
    }
    
    // 等待子线程结束
    handle.join().unwrap();
}
```

### 线程间移动数据
```rust
fn move_data_between_threads() {
    let v = vec![1, 2, 3];
    
    // 使用move关键字将所有权移动到新线程
    let handle = thread::spawn(move || {
        println!("Here's a vector: {:?}", v);
        // v的所有权在这里，主线程不能再使用v
    });
    
    // println!("{:?}", v);  // 错误！v的所有权已移动
    
    handle.join().unwrap();
}
```

## 消息传递

### 使用通道
```rust
use std::sync::mpsc;  // 多生产者，单消费者
use std::thread;

fn channel_example() {
    // 创建通道
    let (tx, rx) = mpsc::channel();
    
    // 创建发送者线程
    let tx1 = tx.clone();  // 克隆发送者
    thread::spawn(move || {
        let vals = vec![
            String::from("hi"),
            String::from("from"),
            String::from("the"),
            String::from("thread"),
        ];
        
        for val in vals {
            tx1.send(val).unwrap();
            thread::sleep(Duration::from_millis(100));
        }
    });
    
    // 主线程接收消息
    for received in rx {
        println!("Got: {}", received);
    }
}
```

### 异步通道
```rust
use std::sync::mpsc;

fn async_channel() {
    let (tx, rx) = mpsc::sync_channel(3);  // 缓冲区大小为3
    
    thread::spawn(move || {
        for i in 0..10 {
            tx.send(i).unwrap();  // 如果缓冲区满，会阻塞
            println!("Sent: {}", i);
        }
    });
    
    thread::sleep(Duration::from_secs(1));  // 让发送者先发送一些数据
    
    for received in rx {
        println!("Received: {}", received);
        thread::sleep(Duration::from_millis(500));
    }
}
```

## 共享状态并发

### 互斥锁
```rust
use std::sync::{Mutex, Arc};
use std::thread;

fn mutex_example() {
    // 使用Arc实现多线程共享所有权
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut num = counter.lock().unwrap();
            *num += 1;
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
    
    println!("Result: {}", *counter.lock().unwrap());
}
```

### 读写锁
```rust
use std::sync::RwLock;

fn rwlock_example() {
    let lock = RwLock::new(5);
    
    // 多个读取者可以同时访问
    {
        let r1 = lock.read().unwrap();
        let r2 = lock.read().unwrap();
        println!("Readers: {}, {}", *r1, *r2);
    } // r1和r2在这里离开作用域
    
    // 写入者需要独占访问
    {
        let mut w = lock.write().unwrap();
        *w += 1;
        println!("After write: {}", *w);
    }
}
```

## 高级并发模式

### 条件变量
```rust
use std::sync::{Condvar, Mutex};

fn condvar_example() {
    let pair = Arc::new((Mutex::new(false), Condvar::new()));
    let pair2 = Arc::clone(&pair);
    
    thread::spawn(move || {
        let (lock, cvar) = &*pair2;
        let mut started = lock.lock().unwrap();
        *started = true;
        cvar.notify_one();  // 通知等待的线程
    });
    
    let (lock, cvar) = &*pair;
    let mut started = lock.lock().unwrap();
    while !*started {
        started = cvar.wait(started).unwrap();  // 等待条件满足
    }
    
    println!("Thread started!");
}
```

### 屏障
```rust
use std::sync::Barrier;

fn barrier_example() {
    let barrier = Arc::new(Barrier::new(3));  // 等待3个线程
    let mut handles = vec![];
    
    for i in 0..3 {
        let barrier = Arc::clone(&barrier);
        let handle = thread::spawn(move || {
            println!("Thread {} before barrier", i);
            barrier.wait();  // 等待所有线程到达
            println!("Thread {} after barrier", i);
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
}
```

## 异步编程

### async/await基础
```rust

#[tokio::main]
async fn async_example() {
    let task1 = async_task("Task 1");
```

### 异步通道
```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn async_channel_example() {
    let (tx, mut rx) = mpsc::channel(32);
    
    // 生产者任务
    let producer = tokio::spawn(async move {
        for i in 0..10 {
            tx.send(i).await.unwrap();
            tokio::time::sleep(Duration::from_millis(100)).await;
        }
    });
    
    // 消费者任务
    let consumer = tokio::spawn(async move {
        while let Some(message) = rx.recv().await {
            println!("Received: {}", message);
        }
    });
    
    tokio::join!(producer, consumer);
}
```

## 原子操作

### 原子类型
```rust
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;

fn atomic_example() {
    let atomic = Arc::new(AtomicUsize::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let atomic = Arc::clone(&atomic);
        let handle = thread::spawn(move || {
            for _ in 0..1000 {
                atomic.fetch_add(1, Ordering::SeqCst);
            }
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
    
    println!("Final count: {}", atomic.load(Ordering::SeqCst));
}
```

```rust
fn memory_ordering() {
    let atomic = AtomicUsize::new(0);
    
    // Relaxed - 最弱的一致性
    atomic.store(1, Ordering::Relaxed);
    
    // Release-Acquire - 同步对
```

## 线程池模式

### 简单的线程池
```rust
use std::sync::{mpsc, Arc, Mutex};
use std::thread;

type Job = Box<dyn FnOnce() + Send + 'static>;

struct ThreadPool {
    workers: Vec<Worker>,
    sender: mpsc::Sender<Job>,
}

impl ThreadPool {
    fn new(size: usize) -> ThreadPool {
        assert!(size > 0);
        
        let (sender, receiver) = mpsc::channel();
        let receiver = Arc::new(Mutex::new(receiver));
        
        let mut workers = Vec::with_capacity(size);
        
        for id in 0..size {
            workers.push(Worker::new(id, Arc::clone(&receiver)));
        }
        
        ThreadPool { workers, sender }
    }
    
    fn execute<F>(&self, f: F)
    where
        F: FnOnce() + Send + 'static,
    {
        let job = Box::new(f);
        self.sender.send(job).unwrap();
    }
}

struct Worker {
    id: usize,
    thread: thread::JoinHandle<()>,
}

impl Worker {
    fn new(id: usize, receiver: Arc<Mutex<mpsc::Receiver<Job>>>) -> Worker {
        let thread = thread::spawn(move || loop {
            let job = receiver.lock().unwrap().recv().unwrap();
            println!("Worker {} got a job; executing.", id);
            job();
        });
        
        Worker { id, thread }
    }
}
```

## 并发安全模式

### Send和Sync trait
```rust

// Sync - 类型可以安全地在多个线程间共享引用
```

### 无锁数据结构
```rust
use std::sync::atomic::{AtomicBool, Ordering};

struct SpinLock<T> {
    locked: AtomicBool,
    data: std::cell::UnsafeCell<T>,
}

impl<T> SpinLock<T> {
    fn new(data: T) -> Self {
        SpinLock {
            locked: AtomicBool::new(false),
            data: std::cell::UnsafeCell::new(data),
        }
    }
    
    fn lock(&self) -> SpinLockGuard<T> {
        while self.locked.compare_and_swap(false, true, Ordering::Acquire) {
            // 自旋等待
        }
        SpinLockGuard { lock: self }
    }
}

struct SpinLockGuard<'a, T> {
    lock: &'a SpinLock<T>,
}

impl<'a, T> Drop for SpinLockGuard<'a, T> {
    fn drop(&mut self) {
        self.lock.locked.store(false, Ordering::Release);
    }
}

impl<'a, T> std::ops::Deref for SpinLockGuard<'a, T> {
    type Target = T;
    
    fn deref(&self) -> &T {
        unsafe { &*self.lock.data.get() }
    }
}

impl<'a, T> std::ops::DerefMut for SpinLockGuard<'a, T> {
    fn deref_mut(&mut self) -> &mut T {
        unsafe { &mut *self.lock.data.get() }
    }
}
```

## 性能优化技巧

### 减少锁竞争
```rust
fn reduce_lock_contention() {
    // 使用细粒度锁
    struct Data {
        counter1: Mutex<i32>,
        counter2: Mutex<i32>,
    }
    
    let data = Arc::new(Data {
        counter1: Mutex::new(0),
        counter2: Mutex::new(0),
    });
    
    // 不同的线程可以同时访问不同的计数器
    let data1 = Arc::clone(&data);
    let handle1 = thread::spawn(move || {
        for _ in 0..1000 {
            *data1.counter1.lock().unwrap() += 1;
        }
    });
    
    let data2 = Arc::clone(&data);
    let handle2 = thread::spawn(move || {
        for _ in 0..1000 {
            *data2.counter2.lock().unwrap() += 1;
        }
    });
    
    handle1.join().unwrap();
    handle2.join().unwrap();
}
```

### 使用无锁算法
```rust
use std::sync::atomic::AtomicPtr;

struct LockFreeStack<T> {
    head: AtomicPtr<Node<T>>,
}

struct Node<T> {
    data: T,
    next: *mut Node<T>,
}

impl<T> LockFreeStack<T> {
    fn new() -> Self {
        LockFreeStack {
            head: AtomicPtr::new(std::ptr::null_mut()),
        }
    }
    
    fn push(&self, data: T) {
        let new_node = Box::into_raw(Box::new(Node {
            data,
            next: std::ptr::null_mut(),
        }));
        
        loop {
            let head = self.head.load(Ordering::Acquire);
            unsafe {
                (*new_node).next = head;
            }
            
            if self.head.compare_and_swap(head, new_node, Ordering::Release) == head {
                break;
            }
        }
    }
    
    fn pop(&self) -> Option<T> {
        loop {
            let head = self.head.load(Ordering::Acquire);
            if head.is_null() {
                return None;
            }
            
            let next = unsafe { (*head).next };
            
            if self.head.compare_and_swap(head, next, Ordering::Release) == head {
                let data = unsafe {
                    let boxed_node = Box::from_raw(head);
                    boxed_node.data
                };
                return Some(data);
            }
        }
    }
}
```

## 总结
Rust的并发编程模型通过类型系统在编译期防止数据竞争，提供了安全且高效的并发原语。从简单的线程到复杂的无锁数据结构，Rust为各种并发场景提供了强大的工具。
