# Rust语法基础

## 变量和可变性

### 变量声明
```rust
fn main() {
    // 不可变变量（默认）
    let x = 5;
    // x = 6; // 错误：不能修改不可变变量
    
    // 可变变量
    let mut y = 5;
    y = 6; // 正确
    
    // 常量
    const MAX_POINTS: u32 = 100_000;
}
```

### 变量遮蔽（Shadowing）
```rust
fn main() {
    let x = 5;
    let x = x + 1; // 遮蔽，创建新变量
    let x = x * 2; // 再次遮蔽
    println!("x = {}", x); // 输出: x = 12
    
    // 类型可以改变
    let spaces = "   ";
    let spaces = spaces.len(); // 从字符串变为数字
}
```

## 数据类型

### 标量类型
```rust
fn main() {
    // 整数类型
    let a: i32 = 42;      // 有符号32位整数
    let b: u64 = 100;     // 无符号64位整数
    
    // 浮点数类型
    let c: f32 = 3.14;    // 单精度浮点数
    let d: f64 = 2.718;   // 双精度浮点数
    
    // 布尔类型
    let e: bool = true;
    
    // 字符类型
    let f: char = '😀';   // Unicode标量值
}
```

### 复合类型
```rust
fn main() {
    // 元组
    let tup: (i32, f64, u8) = (500, 6.4, 1);
    let (x, y, z) = tup;  // 解构
    println!("y = {}", y); // 输出: y = 6.4
    
    // 数组（固定长度）
    let arr = [1, 2, 3, 4, 5];
    let first = arr[0];   // 访问元素
    
    // 切片
    let slice = &arr[1..3]; // [2, 3]
}
```

## 函数

### 函数定义
```rust
// 带返回值的函数
fn add(x: i32, y: i32) -> i32 {
    x + y  // 没有分号，这是表达式
}

// 无返回值的函数（返回unit类型）
fn print_hello() {
    println!("Hello!");
}

fn main() {
    let result = add(5, 3);
    println!("5 + 3 = {}", result);
    print_hello();
}
```

### 表达式和语句
```rust
fn main() {
    // 语句：执行操作但不返回值
    let x = 6; // 这是语句
    
    // 表达式：计算并返回值
    let y = {
        let x = 3;
        x + 1  // 没有分号，这是表达式
    };
    
    println!("y = {}", y); // 输出: y = 4
}
```

## 控制流

### if表达式
```rust
fn main() {
    let number = 6;
    
    if number % 4 == 0 {
        println!("number is divisible by 4");
    } else if number % 3 == 0 {
        println!("number is divisible by 3");
    } else {
        println!("number is not divisible by 4 or 3");
    }
    
    // if是表达式，可以赋值
    let condition = true;
    let number = if condition { 5 } else { 6 };
    println!("number = {}", number);
}
```

### 循环
```rust
fn main() {
    // loop循环（无限循环）
    let mut counter = 0;
    let result = loop {
        counter += 1;
        if counter == 10 {
            break counter * 2; // 从循环中返回值
        }
    };
    println!("result = {}", result); // 输出: result = 20
    
    // while循环
    let mut number = 3;
    while number != 0 {
        println!("{}", number);
        number -= 1;
    }
    
    // for循环（遍历集合）
    let arr = [10, 20, 30, 40, 50];
    for element in arr.iter() {
        println!("value: {}", element);
    }
    
    // 范围循环
    for number in (1..4).rev() {
        println!("{}", number);
    }
}
```

## 模式匹配

### match表达式
```rust
fn main() {
    let number = 13;
    
    match number {
        1 => println!("One!"),
        2 | 3 | 5 | 7 | 11 => println!("Prime!"),
        13..=19 => println!("Teen!"),
        _ => println!("Other!"),
    }
    
    // match也是表达式
    let boolean = true;
    let binary = match boolean {
        false => 0,
        true => 1,
    };
    println!("binary = {}", binary);
}
```

### if let简洁语法
```rust
fn main() {
    let some_value = Some(5);
    
    // 使用match
    match some_value {
        Some(3) => println!("three"),
        _ => (),
    }
    
    // 使用if let（更简洁）
    if let Some(3) = some_value {
        println!("three");
    }
}
```

## 错误处理

### Result类型
```rust
use std::fs::File;
use std::io::ErrorKind;

fn main() {
    let f = File::open("hello.txt");
    
    let f = match f {
        Ok(file) => file,
        Err(error) => match error.kind() {
            ErrorKind::NotFound => match File::create("hello.txt") {
                Ok(fc) => fc,
                Err(e) => panic!("创建文件失败: {:?}", e),
            },
            other_error => {
                panic!("打开文件失败: {:?}", other_error)
            }
        },
    };
}
```

### 更简洁的错误处理
```rust
use std::fs::File;

fn main() {
    // 使用unwrap（出错时panic）
    let f = File::open("hello.txt").unwrap();
    
    // 使用expect（自定义错误信息）
    let f = File::open("hello.txt").expect("打开文件失败");
    
    // 使用?操作符传播错误
    let result = read_file();
    if let Err(e) = result {
        println!("错误: {}", e);
    }
}

fn read_file() -> Result<String, std::io::Error> {
    let mut s = String::new();
    std::fs::File::open("hello.txt")?.read_to_string(&mut s)?;
    Ok(s)
}
```

## 常用宏

### println!宏
```rust
fn main() {
    let name = "Alice";
    let age = 30;
    
    // 基本格式化
    println!("Hello, {}! You are {} years old.", name, age);
    
    // 位置参数
    println!("{1} is {0} years old", age, name);
    
    // 命名参数
    println!("{name} is {age} years old", name = name, age = age);
    
    // 调试输出
    println!("{:?}", (name, age));
}
```

### vec!宏
```rust
fn main() {
    // 创建向量
    let v = vec![1, 2, 3];
    
    // 创建重复元素的向量
    let v2 = vec![0; 5]; // [0, 0, 0, 0, 0]
    
    println!("v = {:?}", v);
    println!("v2 = {:?}", v2);
}
```

## 总结

Rust的语法设计强调安全性和表达力：
- **变量默认不可变**，需要显式声明可变性
- **强类型系统**，但支持类型推断
- **表达式导向**，很多结构都是表达式
- **模式匹配**提供强大的条件判断能力
- **错误处理**通过Result类型强制处理

这些特性使得Rust代码既安全又表达力强，是学习Rust的重要基础。
