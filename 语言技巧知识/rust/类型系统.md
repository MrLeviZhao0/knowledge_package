# Rust类型系统

## 概述
Rust的类型系统是其内存安全和零成本抽象的核心。通过强大的类型推断、所有权系统和trait机制，Rust在编译期就能捕获许多运行时错误。

## 基本类型系统

### 标量类型
```rust
// 整数类型
let x: i32 = 42;           // 有符号32位整数
let y: u64 = 100;          // 无符号64位整数
let z: isize = -10;        // 指针大小的有符号整数

// 浮点类型
let a: f32 = 3.14;         // 单精度浮点
let b: f64 = 2.718;        // 双精度浮点

// 布尔类型
let flag: bool = true;

// 字符类型（Unicode标量值）
let ch: char = '🦀';
```

### 复合类型
```rust
// 元组 - 固定大小的异构集合
let tuple: (i32, f64, char) = (10, 3.14, 'a');
let (x, y, z) = tuple;     // 解构
let first = tuple.0;       // 索引访问

// 数组 - 固定大小的同构集合
let arr: [i32; 5] = [1, 2, 3, 4, 5];
let first = arr[0];

// 切片 - 数组的视图
let slice: &[i32] = &arr[1..3];  // [2, 3]
```

## 所有权系统

### 所有权规则
```rust
fn ownership_basics() {
    let s1 = String::from("hello");  // s1拥有字符串
    let s2 = s1;                     // 所有权转移到s2
    // println!("{}", s1);           // 错误！s1不再有效
    
    let s3 = s2.clone();             // 深度拷贝
    println!("{}", s2);             // s2仍然有效
    println!("{}", s3);             // s3是副本
}
```

### 借用和引用
```rust
fn borrowing_example() {
    let mut s = String::from("hello");
    
    // 不可变借用（多个同时存在）
    let r1 = &s;
    let r2 = &s;
    println!("{}, {}", r1, r2);
    
    // 可变借用（独占）
    let r3 = &mut s;
    r3.push_str(", world!");
    // println!("{}", r1);          // 错误！存在可变借用时不能有不可变借用
}
```

### 生命周期
```rust
// 显式生命周期注解
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}

fn lifetime_example() {
    let string1 = String::from("long string");
    let result;
    {
        let string2 = String::from("short");
        result = longest(string1.as_str(), string2.as_str());
    }
    // println!("{}", result);      // 错误！string2的生命周期不够长
}
```

## Trait系统

### 定义和实现trait
```rust
// 定义trait
pub trait Summary {
    fn summarize(&self) -> String;
    
    // 默认实现
    fn summarize_author(&self) -> String {
        String::from("(Unknown author)")
    }
}

// 为类型实现trait
struct NewsArticle {
    headline: String,
    location: String,
    author: String,
    content: String,
}

impl Summary for NewsArticle {
    fn summarize(&self) -> String {
        format!("{}, by {} ({})", self.headline, self.author, self.location)
    }
    
    fn summarize_author(&self) -> String {
        self.author.clone()
    }
}
```

### Trait对象和动态分发
```rust
// 使用trait对象实现多态
fn notify(item: &dyn Summary) {
    println!("Breaking news! {}", item.summarize());
}

// 返回trait对象
fn returns_summarizable() -> Box<dyn Summary> {
    Box::new(NewsArticle {
        headline: String::from("Rust is awesome!"),
        location: String::from("Internet"),
        author: String::from("Ferris"),
        content: String::from("..."),
    })
}
```

## 智能指针和类型转换

### 常见智能指针
```rust
use std::rc::Rc;
use std::cell::RefCell;

fn smart_pointers() {
    // Box - 堆分配
    let b = Box::new(5);
    println!("b = {}", b);
    
    // Rc - 引用计数
    let rc1 = Rc::new(String::from("shared"));
    let rc2 = Rc::clone(&rc1);
    println!("count: {}", Rc::strong_count(&rc1));
    
    // RefCell - 内部可变性
    let refcell = RefCell::new(42);
    {
        let mut mutable_ref = refcell.borrow_mut();
        *mutable_ref += 1;
    }
    println!("value: {}", refcell.borrow());
}
```

## 模式匹配和类型解构

### 模式匹配
```rust
fn pattern_matching() {
    let some_value = Some(5);
    
    match some_value {
        Some(x) if x > 0 => println!("Positive: {}", x),
        Some(0) => println!("Zero"),
        Some(_) => println!("Negative"),
        None => println!("Nothing"),
    }
    
    // if let 语法糖
    if let Some(x) = some_value {
        println!("Got value: {}", x);
    }
    
    // while let 循环
    let mut stack = Vec::new();
    stack.push(1);
    stack.push(2);
    stack.push(3);
    
    while let Some(top) = stack.pop() {
        println!("{}", top);
    }
}
```

### 生命周期省略规则
```rust
// 编译器自动推断生命周期的规则：
// 1. 每个引用参数获得独自的生命周期
// 2. 如果只有一个输入生命周期，它被赋予所有输出生命周期
// 3. 如果有多个输入生命周期，但其中一个是&self或&mut self，则self的生命周期被赋予所有输出生命周期

// 这些规则应用前
fn first_word_v1<'a>(s: &'a str) -> &'a str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}

// 规则应用后（可以省略生命周期）
fn first_word_v2(s: &str) -> &str {
    let bytes = s.as_bytes();
    for (i, &item) in bytes.iter().enumerate() {
        if item == b' ' {
            return &s[0..i];
        }
    }
    &s[..]
}
```

## 实战技巧

### 错误处理模式
```rust
use std::fs::File;
use std::io::{self, Read};

fn read_username_from_file() -> Result<String, io::Error> {
    // 使用?操作符传播错误
    let mut file = File::open("username.txt")?;
    let mut username = String::new();
    file.read_to_string(&mut username)?;
    Ok(username)
}

// 组合错误类型
type AppResult<T> = Result<T, Box<dyn std::error::Error>>;
```
