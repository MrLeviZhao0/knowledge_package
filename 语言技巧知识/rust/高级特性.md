# Rust高级特性

## 概述
Rust的高级特性包括宏系统、高级trait、生命周期省略、unsafe代码等，这些特性使得Rust能够实现零成本抽象和系统级编程能力。

## 宏系统

### 声明宏
```rust
// 基础声明宏
macro_rules! vec {
    // 空向量
    () => {
        Vec::new()
    };
    
    // 一个元素重复多次
    ($elem:expr; $n:expr) => {
        std::vec::from_elem($elem, $n)
    };
    
    // 多个元素
    ($($x:expr),+ $(,)?) => {
        {
            let mut temp_vec = Vec::new();
            $(temp_vec.push($x);)+
            temp_vec
        }
    };
}

fn main() {
    let v1 = vec![];           // 空向量
    let v2 = vec![1; 5];       // [1, 1, 1, 1, 1]
    let v3 = vec![1, 2, 3];    // [1, 2, 3]
    
    println!("{:?}, {:?}, {:?}", v1, v2, v3);
}
```

```rust
use quote::quote;
use syn;

#[proc_macro_derive(HelloMacro)]
pub fn hello_macro_derive(input: TokenStream) -> TokenStream {
    let ast = syn::parse(input).unwrap();
    impl_hello_macro(&ast)
}

fn impl_hello_macro(ast: &syn::DeriveInput) -> TokenStream {
    let name = &ast.ident;
    let gen = quote! {
        impl HelloMacro for #name {
            fn hello_macro() {
                println!("Hello, Macro! My name is {}!", stringify!(#name));
            }
        }
    };
    gen.into()
}

// 使用自定义派生宏

    Pancakes::hello_macro(); // 输出: "Hello, Macro! My name is Pancakes!"
}
```

## 高级Trait特性

### 关联类型
```rust
pub trait Iterator {
    type Item; // 关联类型
    
    fn next(&mut self) -> Option<Self::Item>;
}

// 实现自定义迭代器
struct Counter {
    count: u32,
}

impl Counter {
    fn new() -> Counter {
        Counter { count: 0 }
    }
}

impl Iterator for Counter {
    type Item = u32;
    
    fn next(&mut self) -> Option<Self::Item> {
        if self.count < 5 {
            self.count += 1;
            Some(self.count)
        } else {
            None
        }
    }
}

fn main() {
    let mut counter = Counter::new();
    
    while let Some(num) = counter.next() {
        println!("Count: {}", num);
    }
}
```

### 完全限定语法
```rust
trait Pilot {
    fn fly(&self);
}

trait Wizard {
    fn fly(&self);
}

struct Human;

impl Pilot for Human {
    fn fly(&self) {
        println!("This is your captain speaking.");
    }
}

impl Wizard for Human {
    fn fly(&self) {
        println!("Up!");
    }
}

impl Human {
    fn fly(&self) {
        println!("*waving arms furiously*");
    }
}

fn main() {
    let person = Human;
    
    // 消除歧义的三种方式
    
    // 1. 直接调用实现的方法
    person.fly(); // 调用Human的fly
    
    // 2. 使用as关键字
    Pilot::fly(&person); // 调用Pilot的fly
    Wizard::fly(&person); // 调用Wizard的fly
    
    // 3. 完全限定语法
    <Human as Pilot>::fly(&person);
    <Human as Wizard>::fly(&person);
}
```

```rust
// 生命周期子类型：'a 至少和 'b 一样长
fn longest_with_announcement<'a, 'b: 'a>(
    x: &'a str,
    y: &'a str,
    ann: &'b str,
) -> &'a str

    'b: 'a, // 'b 必须比 'a 生命周期长

    } else {
        y
    }
}

fn main() {

    let string2 = "xyz";
    let announcement = "Important announcement";
    
    let result = longest_with_announcement(string1.as_str(), string2, announcement);
```

### 高阶trait边界（HRTB）
```rust
// 高阶trait边界：对于所有生命周期 'a
fn call_on_ref_zero<F>(f: F)
where
    F: for<'a> Fn(&'a i32), // F必须能接受任意生命周期的引用
{
    let zero = 0;
    f(&zero);
}

// 闭包实现
fn main() {
    let print = |x: &i32| println!("x = {}", x);
    call_on_ref_zero(print);
    
    // 更复杂的例子
    let mut counter = 0;
    let mut increment_and_print = |x: &i32| {
        counter += 1;
        println!("x = {}, counter = {}", x, counter);
    };
    
    call_on_ref_zero(increment_and_print);
}
```

## 高级模式匹配

### 守卫条件
```rust
fn match_guards() {
    let num = Some(4);
    
    match num {
        Some(x) if x < 5 => println!("Less than 5: {}", x),
        Some(x) if x > 10 => println!("Greater than 10: {}", x),
        Some(x) => println!("{}", x),
        None => println!("Nothing"),
    }
    
    // 复杂守卫
    let point = (3, 5);
    
    match point {
        (x, y) if x == y => println!("On the line x = y"),
        (x, y) if x == 0 => println!("On the y-axis"),
        (x, y) if y == 0 => println!("On the x-axis"),
        (x, y) => println!("({}, {})", x, y),
    }
}

fn main() {
    match_guards();
}
```

### @绑定
```rust
fn at_binding() {
    enum Message {
        Hello { id: i32 },
    }
    
    let msg = Message::Hello { id: 5 };
    
    match msg {
        Message::Hello { 
            id: id_variable @ 3..=7, // 将匹配的值绑定到变量
        } => {
            println!("Found an id in range: {}", id_variable)
        }
        Message::Hello { id: 10..=12 } => {
            println!("Found an id in another range")
        }
        Message::Hello { id } => {
            println!("Found some other id: {}", id)
        }
    }
    
    // 更复杂的@绑定
    let x = 5;
    
    match x {
        e @ 1..=5 => println!("got a range element {}", e),
        e @ 6..=10 => println!("got another range element {}", e),
        _ => println!("anything"),
    }
}

fn main() {
    at_binding();
}
```

## 高级错误处理

### 错误转换
```rust
use std::fs::File;
use std::io::{self, Read};
use std::num::ParseIntError;

// 自定义错误类型
#[derive(Debug)]
enum MyError {
    Io(io::Error),
    Parse(ParseIntError),
    Custom(String),
}

impl From<io::Error> for MyError {
    fn from(error: io::Error) -> Self {
        MyError::Io(error)
    }
}

impl From<ParseIntError> for MyError {
    fn from(error: ParseIntError) -> Self {
        MyError::Parse(error)
    }
}

// 使用?操作符自动转换错误
fn read_and_parse_file() -> Result<i32, MyError> {
    let mut file = File::open("number.txt")?; // io::Error -> MyError
    let mut contents = String::new();
    file.read_to_string(&mut contents)?; // io::Error -> MyError
    
    let number: i32 = contents.trim().parse()?; // ParseIntError -> MyError
    Ok(number)
}

// 错误链
fn process_data() -> Result<(), MyError> {
    let number = read_and_parse_file()?;
    
    if number < 0 {
        return Err(MyError::Custom("Number must be positive".to_string()));
    }
    
    println!("Processed number: {}", number);
    Ok(())
}

fn main() {
    match process_data() {
        Ok(()) => println!("Success!"),
        Err(e) => println!("Error: {:?}", e),
    }
}
```

## 高级并发模式

### 原子操作
```rust
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;
use std::thread;

fn atomic_operations() {
    let atomic = Arc::new(AtomicUsize::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let atomic = Arc::clone(&atomic);
        let handle = thread::spawn(move || {
            for _ in 0..1000 {
                // 原子增加
                atomic.fetch_add(1, Ordering::SeqCst);
            }
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
    
    println!("Final count: {}", atomic.load(Ordering::SeqCst));
}

// 无锁数据结构
use std::sync::atomic::AtomicPtr;

struct LockFreeStack<T> {
    head: AtomicPtr<Node<T>>,
}

struct Node<T> {
    data: T,
    next: *mut Node<T>,
}

impl<T> LockFreeStack<T> {
    fn new() -> Self {
        LockFreeStack {
            head: AtomicPtr::new(std::ptr::null_mut()),
        }
    }
    
    fn push(&self, data: T) {
        let new_node = Box::into_raw(Box::new(Node {
            data,
            next: std::ptr::null_mut(),
        }));
        
        loop {
            let head = self.head.load(Ordering::Acquire);
            unsafe {
                (*new_node).next = head;
            }
            
            if self.head.compare_and_swap(head, new_node, Ordering::Release) == head {
                break;
            }
        }
    }
    
    fn pop(&self) -> Option<T> {
        loop {
            let head = self.head.load(Ordering::Acquire);
            if head.is_null() {
                return None;
            }
            
            let next = unsafe { (*head).next };
            
            if self.head.compare_and_swap(head, next, Ordering::Release) == head {
                unsafe {
                    let data = Box::from_raw(head).data;
                    return Some(data);
                }
            }
        }
    }
}

fn main() {
    atomic_operations();
    
    let stack = LockFreeStack::new();
    stack.push(1);
    stack.push(2);
    stack.push(3);
    
    while let Some(value) = stack.pop() {
        println!("Popped: {}", value);
    }
}
```

## 总结
Rust的高级特性提供了强大的抽象能力和系统级控制：

1. **宏系统**：编译时代码生成和元编程
2. **高级Trait**：关联类型、泛型约束、完全限定语法
3. **生命周期**：子类型、高阶trait边界
4. **Unsafe Rust**：系统级编程和外部函数接口
5. **高级模式匹配**：守卫条件、@绑定
6. **高级类型系统**：永不返回类型、动态大小类型
7. **错误处理**：错误转换和上下文
8. **并发模式**：原子操作和无锁数据结构

这些特性使得Rust能够在保持内存安全的同时，实现高性能的系统级编程。
