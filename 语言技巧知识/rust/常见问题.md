# 常见问题

## 概述
本章收集了Rust开发中常见的问题和解决方案，涵盖所有权系统、生命周期、并发编程、性能优化等多个方面，帮助开发者快速解决实际问题。

## 所有权和借用问题

### 问题1: 所有权转移后无法使用变量

**错误示例：**
```rust
fn main() {
    let s1 = String::from("hello");
    let s2 = s1; // 所有权转移
    
    println!("{}", s1); // 编译错误：s1已移动
}
```

**解决方案：**
```rust
// 方案1：使用克隆
fn main() {
    let s1 = String::from("hello");
    let s2 = s1.clone(); // 显式克隆
    
    println!("s1: {}, s2: {}", s1, s2); // 正确
}

// 方案2：使用引用
fn main() {
    let s1 = String::from("hello");
    let s2 = &s1; // 借用而不是移动
    
    println!("s1: {}, s2: {}", s1, s2); // 正确
}

// 方案3：实现Copy trait
#[derive(Copy, Clone)]
struct Point {
    x: i32,
    y: i32,
}

fn main() {
    let p1 = Point { x: 1, y: 2 };
    let p2 = p1; // 拷贝而不是移动
    
    println!("p1: ({}, {}), p2: ({}, {})", p1.x, p1.y, p2.x, p2.y); // 正确
}
```

### 问题2: 可变和不可变借用冲突

**错误示例：**
```rust
fn main() {
    let mut v = vec![1, 2, 3];
    
    let first = &v[0]; // 不可变借用
    v.push(4); // 编译错误：可变借用与不可变借用冲突
    
    println!("第一个元素: {}", first);
}
```

**解决方案：**
```rust
// 方案1：分离作用域
fn main() {
    let mut v = vec![1, 2, 3];
    
    {
        let first = &v[0]; // 不可变借用
        println!("第一个元素: {}", first);
    } // first离开作用域，借用结束
    
    v.push(4); // 现在可以可变借用
    println!("向量: {:?}", v);
}

// 方案2：使用索引而不是引用
fn main() {
    let mut v = vec![1, 2, 3];
    
    let first = v[0]; // 拷贝值而不是借用
    v.push(4);
    
    println!("第一个元素: {}", first);
    println!("向量: {:?}", v);
}

// 方案3：使用get方法
fn main() {
    let mut v = vec![1, 2, 3];
    
    if let Some(first) = v.get(0) {
        println!("第一个元素: {}", first);
    }
    
    v.push(4);
    println!("向量: {:?}", v);
}
```

## 生命周期问题

### 问题3: 生命周期注解错误

**错误示例：**
```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

fn main() {
    let string1 = String::from("长的字符串");
    let result;
    
    {
        let string2 = String::from("xyz");
        result = longest(string1.as_str(), string2.as_str());
    } // string2离开作用域
    
    println!("最长的字符串是: {}", result); // 编译错误：result引用已释放的内存
}
```

**解决方案：**
```rust
// 方案1：调整生命周期注解
fn longest<'a>(x: &'a str, y: &str) -> &'a str {
    x // 只返回与x相同生命周期的引用
}

fn main() {
    let string1 = String::from("长的字符串");
    let result;
    
    {
        let string2 = String::from("xyz");
        result = longest(string1.as_str(), string2.as_str());
    }
    
    println!("最长的字符串是: {}", result); // 正确
}

// 方案2：使用owned类型
fn longest_owned(x: String, y: String) -> String {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

fn main() {
    let string1 = String::from("长的字符串");
    let result;
    
    {
        let string2 = String::from("xyz");
        result = longest_owned(string1, string2);
    }
    
    println!("最长的字符串是: {}", result); // 正确
}

// 方案3：使用智能指针
use std::rc::Rc;

fn longest_rc(x: Rc<String>, y: Rc<String>) -> Rc<String> {
    if x.len() > y.len() {
        x
    } else {
        y
    }
}

fn main() {
    let string1 = Rc::new(String::from("长的字符串"));
    let result;
    
    {
        let string2 = Rc::new(String::from("xyz"));
        result = longest_rc(Rc::clone(&string1), Rc::clone(&string2));
    }
    
    println!("最长的字符串是: {}", result); // 正确
}
```

### 问题4: 结构体生命周期注解

**错误示例：**
```rust
struct ImportantExcerpt {
```

## 并发编程问题

### 问题5: 多线程数据竞争

**错误示例：**
```rust
use std::thread;

fn main() {
    let mut counter = 0;
    
    let handle = thread::spawn(|| {
        for _ in 0..1000 {
            counter += 1; // 编译错误：counter可能比线程存活时间更长
        }
    });
    
    handle.join().unwrap();
    
    println!("计数: {}", counter);
}
```

**解决方案：**
```rust
// 方案1：使用Arc和Mutex
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let counter = Arc::new(Mutex::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            let mut num = counter.lock().unwrap();
            *num += 1;
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
    
    println!("最终计数: {}", *counter.lock().unwrap());
}

// 方案2：使用原子类型
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;

fn main() {
    let counter = Arc::new(AtomicUsize::new(0));
    let mut handles = vec![];
    
    for _ in 0..10 {
        let counter = Arc::clone(&counter);
        let handle = thread::spawn(move || {
            for _ in 0..1000 {
                counter.fetch_add(1, Ordering::SeqCst);
            }
        });
        handles.push(handle);
    }
    
    for handle in handles {
        handle.join().unwrap();
    }
    
    println!("最终计数: {}", counter.load(Ordering::SeqCst));
}

// 方案3：使用消息传递
use std::sync::mpsc;

fn main() {
    let (tx, rx) = mpsc::channel();
    let mut handles = vec![];
    
    for i in 0..10 {
        let tx = tx.clone();
        let handle = thread::spawn(move || {
            tx.send(i).unwrap();
        });
        handles.push(handle);
    }
    
    drop(tx); // 关闭发送端
    
    let mut results = vec![];
    for received in rx {
        results.push(received);
    }
    
    println!("结果: {:?}", results);
}
```

**错误示例：**

## 错误处理问题

### 问题7: Result和Option处理

**错误示例：**
```rust
use std::fs::File;
use std::io::Read;

fn read_file(path: &str) -> String {
    let mut file = File::open(path).unwrap(); // 可能panic
    let mut contents = String::new();
    file.read_to_string(&mut contents).unwrap(); // 可能panic
    contents
}

fn main() {
    let content = read_file("nonexistent.txt"); // 程序崩溃
    println!("文件内容: {}", content);
}
```

**解决方案：**
```rust
// 方案1：使用Result和模式匹配
use std::fs::File;
use std::io::{self, Read};

fn read_file(path: &str) -> Result<String, io::Error> {
    let mut file = match File::open(path) {
        Ok(file) => file,
        Err(e) => return Err(e),
    };
    
    let mut contents = String::new();
    match file.read_to_string(&mut contents) {
        Ok(_) => Ok(contents),
        Err(e) => Err(e),
    }
}

fn main() {
    match read_file("nonexistent.txt") {
        Ok(content) => println!("文件内容: {}", content),
        Err(e) => println!("读取文件失败: {}", e),
    }
}

// 方案2：使用?操作符
fn read_file_simple(path: &str) -> Result<String, io::Error> {
    let mut file = File::open(path)?;
    let mut contents = String::new();
    file.read_to_string(&mut contents)?;
    Ok(contents)
}

// 方案3：使用组合子
fn read_file_with_default(path: &str) -> String {
    read_file_simple(path)
        .unwrap_or_else(|_| "默认内容".to_string())
}

// 方案4：使用anyhow库（需要添加依赖）
use anyhow::{Context, Result};

fn read_file_anyhow(path: &str) -> Result<String> {
    let mut file = File::open(path)
        .with_context(|| format!("无法打开文件: {}", path))?;
    
    let mut contents = String::new();
    file.read_to_string(&mut contents)
        .context("读取文件内容失败")?;
    
    Ok(contents)
}
```

### 问题8: 自定义错误类型

**复杂错误处理：**
```rust
use std::fmt;

#[derive(Debug)]
enum AppError {
    Io(std::io::Error),
    Parse(String),
    Validation(&'static str),
}

impl fmt::Display for AppError {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            AppError::Io(e) => write!(f, "IO错误: {}", e),
            AppError::Parse(s) => write!(f, "解析错误: {}", s),
            AppError::Validation(msg) => write!(f, "验证错误: {}", msg),
        }
    }
}

impl std::error::Error for AppError {
    fn source(&self) -> Option<&(dyn std::error::Error + 'static)> {
        match self {
            AppError::Io(e) => Some(e),
            _ => None,
        }
    }
}

impl From<std::io::Error> for AppError {
    fn from(error: std::io::Error) -> Self {
        AppError::Io(error)
    }
}

fn process_data() -> Result<(), AppError> {
    // 使用?操作符自动转换错误类型
    let data = std::fs::read_to_string("data.txt")?;
    
    if data.is_empty() {
        return Err(AppError::Validation("数据不能为空"));
    }
    
    // 处理逻辑
    Ok(())
}

fn main() {
    if let Err(e) = process_data() {
        eprintln!("错误: {}", e);
        if let Some(source) = e.source() {
            eprintln!("原因: {}", source);
        }
    }
}
```

## 性能优化问题

### 问题9: 不必要的内存分配

**性能问题示例：**
```rust
fn process_strings(strings: &[String]) -> Vec<String> {
    strings.iter()
        .map(|s| s.to_uppercase()) // 每次迭代都分配新字符串
        .collect()
}

fn concatenate_strings(strings: &[String]) -> String {
    let mut result = String::new();
    for s in strings {
        result += s; // 每次拼接都重新分配内存
    }
    result
}
```

**优化方案：**
```rust
// 优化1：预分配内存
fn process_strings_optimized(strings: &[String]) -> Vec<String> {
    let mut result = Vec::with_capacity(strings.len());
    for s in strings {
        result.push(s.to_uppercase());
    }
    result
}

// 优化2：使用StringBuilder模式
fn concatenate_strings_optimized(strings: &[String]) -> String {
    let total_len: usize = strings.iter().map(|s| s.len()).sum();
    let mut result = String::with_capacity(total_len);
    
    for s in strings {
        result.push_str(s);
    }
    result
}

// 优化3：使用Cow（Copy on Write）
use std::borrow::Cow;

fn process_strings_cow<'a>(strings: &'a [String]) -> Vec<Cow<'a, str>> {
    strings.iter()
        .map(|s| {
            if s.chars().all(|c| c.is_ascii_uppercase()) {
                Cow::Borrowed(s.as_str())
            } else {
                Cow::Owned(s.to_uppercase())
            }
        })
        .collect()
}

// 优化4：使用迭代器避免中间集合
fn process_large_data(data: &[i32]) -> i32 {
    data.iter()
        .filter(|&x| x % 2 == 0) // 中间集合1
        .map(|x| x * 2)          // 中间集合2
        .sum()                   // 中间集合3
}

fn process_large_data_optimized(data: &[i32]) -> i32 {
    data.iter()
        .filter(|&x| x % 2 == 0)
        .map(|x| x * 2)
        .fold(0, |acc, x| acc + x) // 无中间集合
}

// 使用序列进一步优化
fn process_large_data_sequence(data: &[i32]) -> i32 {
    data.iter()
        .copied()
        .filter(|x| x % 2 == 0)
        .map(|x| x * 2)
        .sum()
}
```

### 问题10: 缓存不友好

**缓存问题示例：**
```rust
// 缓存不友好的矩阵访问
fn matrix_multiply_naive(a: &[f64], b: &[f64], c: &mut [f64], n: usize) {
    for i in 0..n {
        for j in 0..n {
            for k in 0..n {
                c[i * n + j] += a[i * n + k] * b[k * n + j];
            }
        }
    }
}
```

**优化方案：**
```rust
// 缓存友好的矩阵乘法（分块）
fn matrix_multiply_optimized(a: &[f64], b: &[f64], c: &mut [f64], n: usize) {
    const BLOCK_SIZE: usize = 64; // 根据CPU缓存调整
    
    for i in (0..n).step_by(BLOCK_SIZE) {
        for j in (0..n).step_by(BLOCK_SIZE) {
            for k in (0..n).step_by(BLOCK_SIZE) {
                let i_end = (i + BLOCK_SIZE).min(n);
                let j_end = (j + BLOCK_SIZE).min(n);
                let k_end = (k + BLOCK_SIZE).min(n);
                
                for ii in i..i_end {
                    for kk in k..k_end {
                        let a_val = a[ii * n + kk];
                        for jj in j..j_end {
                            c[ii * n + jj] += a_val * b[kk * n + jj];
                        }
                    }
                }
            }
        }
    }
}

// 使用SIMD指令（x86_64架构）
#[cfg(target_arch = "x86_64")]
use std::arch::x86_64::*;

#[cfg(target_arch = "x86_64")]
unsafe fn matrix_multiply_simd(a: &[f64], b: &[f64], c: &mut [f64], n: usize) {
    for i in 0..n {
        for k in 0..n {
            let a_val = _mm256_set1_pd(a[i * n + k]);
            
            for j in (0..n).step_by(4) {
                let b_val = _mm256_loadu_pd(&b[k * n + j]);
                let c_val = _mm256_loadu_pd(&c[i * n + j]);
                let result = _mm256_fmadd_pd(a_val, b_val, c_val);
                _mm256_storeu_pd(&mut c[i * n + j], result);
            }
        }
    }
}
```
