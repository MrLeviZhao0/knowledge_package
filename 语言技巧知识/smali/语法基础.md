# Smali语法基础

## Smali语言概述

Smali是Dalvik虚拟机字节码的汇编语言表示，用于Android应用的反编译和分析。它基于寄存器架构，与JVM的栈架构有显著区别。

### 基本文件结构

```smali
# 类声明
.class public Lcom/example/MainActivity;
.super Landroid/app/Activity;
.source "MainActivity.java"

# 接口实现
.implements Landroid/view/View$OnClickListener;

# 注解
.annotation runtime Landroid/support/annotation/Keep;
.end annotation

# 字段声明
.field private static final TAG:Ljava/lang/String; = "MainActivity"
.field public instanceField:I

# 方法声明
.method public constructor <init>()V
    .registers 1
    
    .prologue
    .line 10
    invoke-direct {p0}, Landroid/app/Activity;-><init>()V
    
    return-void
.end method
```

## 寄存器系统

### 寄存器类型
```smali
# 参数寄存器 (p0, p1, p2...)
# p0: this引用（实例方法）或第一个参数（静态方法）
# p1, p2...: 方法参数

# 局部变量寄存器 (v0, v1, v2...)
# 用于存储临时计算结果

.method public add(II)I
    .registers 4    # 总共使用4个寄存器
    .param p1, "a"    # I
    .param p2, "b"    # I
    
    # 寄存器分配：
    # p0: this (隐含)
    # p1: 参数a
    # p2: 参数b
    # v0: 临时结果
    
    add-int v0, p1, p2
    return v0
.end method
```

### 寄存器使用规则
```smali
.method public static main([Ljava/lang/String;)V
    .registers 5    # 使用5个寄存器
    .param p0, "args"    # [Ljava/lang/String;
    
    # 寄存器分配示例：
    # p0: args参数
    # v0: 系统输出流
    # v1: 输出字符串
    # v2: 临时计算
    # v3: 循环计数器
    
    sget-object v0, Ljava/lang/System;->out:Ljava/io/PrintStream;
    
    const-string v1, "Hello, World!"
    
    invoke-virtual {v0, v1}, Ljava/io/PrintStream;->println(Ljava/lang/String;)V
    
    return-void
.end method
```

## 指令集详解

### 数据移动指令
```smali
# 常量加载
const/4 v0, 0x1          # v0 = 1 (4位常量)
const/16 v0, 0x100       # v0 = 256 (16位常量)
const v0, 0x12345678     # v0 = 0x12345678 (32位常量)
const-wide v0, 0x123456789abcdef0L  # 64位常量

const-string v0, "hello" # 加载字符串
const-class v0, Ljava/lang/String;  # 加载类对象

# 寄存器间移动
move v0, v1              # v0 = v1 (32位)
move-wide v0, v1         # v0,v1 = v2,v3 (64位)
move-object v0, v1        # 对象引用移动
```

### 算术运算指令
```smali
# 整数运算
add-int v0, v1, v2       # v0 = v1 + v2
sub-int v0, v1, v2       # v0 = v1 - v2
mul-int v0, v1, v2       # v0 = v1 * v2
div-int v0, v1, v2       # v0 = v1 / v2
rem-int v0, v1, v2       # v0 = v1 % v2

# 长整数运算 (64位)
add-long v0, v2, v4      # v0,v1 = v2,v3 + v4,v5

# 浮点数运算
add-float v0, v1, v2     # v0 = v1 + v2 (单精度)
add-double v0, v2, v4    # v0,v1 = v2,v3 + v4,v5 (双精度)
```

### 逻辑运算指令
```smali
# 位运算
and-int v0, v1, v2       # v0 = v1 & v2
or-int v0, v1, v2        # v0 = v1 | v2
xor-int v0, v1, v2       # v0 = v1 ^ v2

# 移位运算
shl-int v0, v1, v2       # v0 = v1 << v2
shr-int v0, v1, v2       # v0 = v1 >> v2 (算术右移)
ushr-int v0, v1, v2      # v0 = v1 >>> v2 (逻辑右移)
```

### 比较指令
```smali
# 整数比较
cmp-long v0, v2, v4      # 比较v2,v3和v4,v5，结果存入v0

# 浮点数比较
cmpg-float v0, v1, v2    # v0 = (v1 > v2) ? 1 : ((v1 == v2) ? 0 : -1)
cmpl-float v0, v1, v2    # 与cmpg-float类似，但处理NaN不同

# 条件跳转基于比较结果
if-eqz v0, :label        # 如果v0 == 0，跳转到label
if-nez v0, :label        # 如果v0 != 0，跳转到label
if-ltz v0, :label        # 如果v0 < 0，跳转到label
if-gtz v0, :label        # 如果v0 > 0，跳转到label
```

### 控制流指令
```smali
# 无条件跳转
goto :label               # 直接跳转到label

# 条件跳转
if-eq v0, v1, :label     # 如果v0 == v1，跳转
if-ne v0, v1, :label     # 如果v0 != v1，跳转
if-lt v0, v1, :label     # 如果v0 < v1，跳转
if-ge v0, v1, :label     # 如果v0 >= v1，跳转
if-gt v0, v1, :label     # 如果v0 > v1，跳转
if-le v0, v1, :label     # 如果v0 <= v1，跳转

# 多条件跳转 (switch)
packed-switch v0, :switch_data
sparse-switch v0, :switch_data
```

### 方法调用指令
```smali
# 直接调用
invoke-direct {v0}, Ljava/lang/Object;-><init>()V
invoke-static {v0, v1}, Ljava/lang/Math;->max(II)I
invoke-virtual {v0, v1}, Ljava/io/PrintStream;->println(Ljava/lang/String;)V

# 接口调用
invoke-interface {v0, v1}, Ljava/util/List;->add(Ljava/lang/Object;)Z

# 超类调用
invoke-super {v0, v1}, Landroid/app/Activity;->onCreate(Landroid/os/Bundle;)V
```

### 数组操作指令
```smali
# 创建数组
new-array v0, v1, [I          # 创建int数组，大小为v1
filled-new-array {v0, v1}, [I  # 创建并初始化数组

# 数组长度
array-length v0, v1           # v0 = v1.length

# 数组访问

```

### 类型转换指令
```smali
# 整数类型转换

int-to-double v0, v1         # v0,v1 = (double)v2

# 浮点数类型转换

# 长整数类型转换

```

## 异常处理

### try-catch块
```smali
.method public riskyMethod()V
    .registers 3
    
    .try_start_0
    # 可能抛出异常的代码
    const-string v0, "test"
    invoke-static {v0}, Ljava/lang/Integer;->parseInt(Ljava/lang/String;)I
    .try_end_0
    .catch Ljava/lang/NumberFormatException; {:try_start_0 .. :try_end_0} :catch_0
    
    return-void
    
    :catch_0
    move-exception v0
    
    # 异常处理代码
    const-string v1, "NumberFormatException"
    invoke-static {v1, v0}, Landroid/util/Log;->e(Ljava/lang/String;Ljava/lang/String;)I
    
    return-void
.end method
```

### 多catch块
```smali
.try_start_0
# 代码
.try_end_0
.catch Ljava/lang/Exception; {:try_start_0 .. :try_end_0} :catch_all
.catch Ljava/lang/NullPointerException; {:try_start_0 .. :try_end_0} :catch_npe
.catch Ljava/lang/IllegalArgumentException; {:try_start_0 .. :try_end_0} :catch_iae

# 处理特定异常
:catch_npe
# NullPointerException处理

:catch_iae  
# IllegalArgumentException处理

:catch_all
# 其他所有异常处理
```

## 实际代码示例分析

### 简单方法反编译
**Java源代码：**
```java
public int calculate(int a, int b) {
    return (a + b) * 2;
}
```

**对应的Smali代码：**
```smali
.method public calculate(II)I
    .registers 4
    .param p1, "a"    # I
    .param p2, "b"    # I
    
    add-int v0, p1, p2    # v0 = a + b
    mul-int/lit8 v0, v0, 2  # v0 = v0 * 2
    return v0
.end method
```

### 循环结构分析
**Java源代码：**
```java
public int sumArray(int[] array) {
    int sum = 0;
    for (int i = 0; i < array.length; i++) {
        sum += array[i];
    }
    return sum;
}
```

**对应的Smali代码：**
```smali
.method public sumArray([I)I
    .registers 6
    .param p1, "array"    # [I
    
    const/4 v0, 0x0        # sum = 0
    const/4 v1, 0x0        # i = 0
    
    :goto_3
    array-length v2, p1    # v2 = array.length
    if-ge v1, v2, :cond_e  # if i < length
    
    aget v2, p1, v1        # v2 = array[i]
    add-int/2addr v0, v2   # sum += array[i]
    
    add-int/lit8 v1, v1, 1 # i++
    goto :goto_3           # 继续循环
    
    :cond_e
    return v0              # 返回sum
.end method
```

## 总结

Smali语法虽然看起来复杂，但掌握了基本规则后就能有效阅读和分析：
- **寄存器系统**是基于寄存器的架构核心
- **指令集**提供了丰富的操作能力
- **类型描述符**是理解方法签名的关键
- **控制流指令**对应Java的各种流程结构

通过系统学习这些基础，您将能够熟练阅读和修改Smali代码，为Android应用分析和安全研究打下坚实基础。
