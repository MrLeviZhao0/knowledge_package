# Kotlin扩展函数

## 概述
扩展函数是Kotlin的强大特性，允许在不修改原有类的情况下为类添加新函数。扩展函数提供了更好的代码组织方式和更自然的API设计。

## 基础语法

### 定义扩展函数
```kotlin
// 为String类添加扩展函数
fun String.addExclamation(): String {
    return "$this!"
}

// 为Int类添加扩展函数
fun Int.isEven(): Boolean {
    return this % 2 == 0
}

// 使用扩展函数
fun main() {
    val greeting = "Hello"
    println(greeting.addExclamation()) // "Hello!"
    
    val number = 4
    println("$number is even: ${number.isEven()}") // true
}
```

### 扩展属性
```kotlin
// 扩展属性 - 实际上不添加字段，只是提供getter/setter
val String.lastChar: Char
    get() = this[length - 1]

val String.firstChar: Char
    get() = this[0]

// 可变扩展属性（需要有setter）
var StringBuilder.lastChar: Char
    get() = get(length - 1)
    set(value) {
        setCharAt(length - 1, value)
    }

fun main() {
    val str = "Kotlin"
    println(str.lastChar) // 'n'
    println(str.firstChar) // 'K'
    
    val sb = StringBuilder("Kotlin")
    sb.lastChar = '!'
    println(sb) // "Kotli!"
}
```

## 实际应用场景

### 集合操作扩展
```kotlin
// 为List添加扩展函数
fun <T> List<T>.secondOrNull(): T? {
    return if (this.size >= 2) this[1] else null
}

fun <T> List<T>.penultimateOrNull(): T? {
    return if (this.size >= 2) this[this.size - 2] else null
}

// 使用
fun main() {
    val numbers = listOf(1, 2, 3, 4, 5)
    println(numbers.secondOrNull()) // 2
    println(numbers.penultimateOrNull()) // 4
    
    val single = listOf(1)
    println(single.secondOrNull()) // null
}
```

### 字符串处理扩展
```kotlin
// 字符串处理扩展
fun String.toTitleCase(): String {
    return this.split(" ").joinToString(" ") { word ->
        word.replaceFirstChar { it.uppercase() }
    }
}

fun String.isPalindrome(): Boolean {
    val clean = this.toLowerCase().replace("[^a-z]".toRegex(), "")
    return clean == clean.reversed()
}

fun String.containsIgnoreCase(other: String): Boolean {
    return this.contains(other, ignoreCase = true)
}

fun main() {
    val text = "hello world"
    println(text.toTitleCase()) // "Hello World"
    
    val palindrome = "A man a plan a canal Panama"
    println("'$palindrome' is palindrome: ${palindrome.isPalindrome()}") // true
    
    println("Hello".containsIgnoreCase("hello")) // true
}
```

## 高级特性

### 泛型扩展函数
```kotlin
// 泛型扩展函数
fun <T> List<T>.randomOrNull(): T? {
    return if (this.isEmpty()) null else this.random()
}

fun <T> Collection<T>.joinToString(
    separator: String = ", ",
    prefix: String = "",
    postfix: String = "",
    transform: (T) -> String = { it.toString() }
): String {
    return this.joinToString(separator, prefix, postfix, transform)
}

// 使用
fun main() {
    val numbers = listOf(1, 2, 3)
    println(numbers.randomOrNull()) // 随机一个元素
    
    val formatted = numbers.joinToString(
        prefix = "[",
        postfix = "]",
        transform = { "Number: $it" }
    )
    println(formatted) // "[Number: 1, Number: 2, Number: 3]"
}
```

### 可空类型的扩展
```kotlin
// 可空类型的扩展函数
fun String?.orEmpty(): String {
    return this ?: ""
}

fun String?.isNullOrBlank(): Boolean {
    return this == null || this.isBlank()
}

fun <T> Collection<T>?.orEmpty(): Collection<T> {
    return this ?: emptyList()
}

// 使用
fun processUserInput(input: String?) {
    val safeInput = input.orEmpty()
    if (safeInput.isNotBlank()) {
        println("Processing: $safeInput")
    }
}

fun main() {
    processUserInput("hello") // "Processing: hello"
    processUserInput(null)     // 不输出
    processUserInput("   ")    // 不输出
}
```

### 中缀扩展函数

```kotlin
// 中缀扩展函数
infix fun Int.times(str: String): String {
```

### 成员扩展函数
```kotlin
class Host {
    // 在类内部定义的扩展函数

    }
```

### 为Java类添加扩展
```kotlin
// 为Java的File类添加扩展
fun File.readText(): String {
    return this.readBytes().toString(Charsets.UTF_8)
}

fun File.writeText(text: String) {
    this.writeBytes(text.toByteArray(Charsets.UTF_8))
}

fun File.appendText(text: String) {
    this.appendBytes(text.toByteArray(Charsets.UTF_8))
}

// 使用
fun main() {
    val file = File("test.txt")
    file.writeText("Hello, World!")
    
    val content = file.readText()
    println(content) // "Hello, World!"
    
    file.appendText("\nAppended text")
    println(file.readText()) // "Hello, World!\nAppended text"
}
```

## 实际应用模式

### DSL构建器模式
```kotlin
// 使用扩展函数创建DSL
class Html {
    private val children = mutableListOf<Any>()
    
    fun body(init: Body.() -> Unit) {
        val body = Body().apply(init)
        children.add(body)
    }
    
    override fun toString(): String {
        return "<html>${children.joinToString("\n")}</html>"
    }
}

class Body {
    private val children = mutableListOf<Any>()
    
    fun h1(text: String) {
        children.add("<h1>$text</h1>")
    }
    
    fun p(text: String) {
        children.add("<p>$text</p>")
    }
    
    override fun toString(): String {
        return "<body>${children.joinToString("\n")}</body>"
    }
}

// 扩展函数使DSL更自然
fun html(init: Html.() -> Unit): Html {
    return Html().apply(init)
}

fun main() {
    val page = html {
        body {
            h1("Welcome")
            p("This is a paragraph")
            p("Another paragraph")
        }
    }
    
    println(page)
}
```

### 工具类替代
```kotlin
// 传统工具类方式（Java风格）
object StringUtils {
    fun capitalize(str: String): String {
        return str.replaceFirstChar { it.uppercase() }
    }
    
    fun isPalindrome(str: String): Boolean {
        return str == str.reversed()
    }
}

// 使用扩展函数（更自然的Kotlin风格）
fun String.capitalize(): String {
    return this.replaceFirstChar { it.uppercase() }
}

fun String.isPalindrome(): Boolean {
    return this == this.reversed()
}

fun main() {
    // 传统方式
    val result1 = StringUtils.capitalize("hello")
    
    // 扩展函数方式（更自然）
    val result2 = "hello".capitalize()
    
    println(result1) // "Hello"
    println(result2) // "Hello"
}
```

## 性能考虑

### 内联扩展函数
```kotlin
// 内联扩展函数（减少函数调用开销）
inline fun <T> Iterable<T>.forEachIndexed(action: (Int, T) -> Unit) {
    var index = 0
    for (item in this) {
        action(index++, item)
    }
}

// 使用
fun main() {
    val list = listOf("a", "b", "c")
    
    list.forEachIndexed { index, item ->
        println("$index: $item")
    }
    
    // 编译后相当于：
    // var index = 0
    // for (item in list) {
    //     println("$index: $item")
    //     index++
    // }
}
```

### 避免过度使用
```kotlin
// 不好的扩展函数（过于具体，用途有限）
fun String.convertToUserSpecificFormat(): String {
    // 过于具体的业务逻辑
    return "User: $this"
}

// 好的扩展函数（通用，可复用）
fun String.withPrefix(prefix: String): String {
    return "$prefix$this"
}

// 使用通用扩展函数
fun formatUserData(userName: String): String {
    return userName.withPrefix("User: ")
}
```

## 总结
Kotlin扩展函数是一项强大的特性，它允许：

1. **增强现有类**：在不修改源代码的情况下为类添加功能
2. **改善API设计**：创建更自然、更易读的代码
3. **替代工具类**：避免静态工具类的使用
4. **创建DSL**：构建领域特定语言
5. **提高代码组织**：将相关功能组织在一起

使用扩展函数时要注意：
- 保持扩展函数的通用性和可复用性
- 避免过度使用，只在确实能改善代码可读性时使用
- 注意扩展函数的可见性和作用域
- 考虑性能影响，必要时使用内联函数
