# Android性能优化常见面试题与知识点

## 1. 内存优化

### 1.1 内存泄漏
**问题**：什么是内存泄漏？如何检测和解决？

**答案要点**：
- 定义：不再使用的对象无法被GC回收
- 常见原因：
  - 静态变量持有Activity引用
  - 非静态内部类持有外部类引用
  - 未注销的监听器
  - 未关闭的资源（Cursor、Stream等）
- 检测工具：
  - Android Studio的Memory Profiler
  - LeakCanary
  - MAT（Memory Analyzer Tool）
- 解决方案：
  - 及时释放资源
  - 使用弱引用
  - 避免静态变量持有Activity引用

### 1.2 内存抖动
**问题**：什么是内存抖动？如何避免？

**答案要点**：
- 定义：短时间内频繁创建和释放对象
- 危害：
  - 触发频繁GC
  - 界面卡顿
  - 电池消耗增加
- 常见场景：
  - onDraw中创建对象
  - 循环中创建临时对象
  - 频繁字符串拼接
- 解决方案：
  - 对象复用（如ViewHolder）
  - 预分配对象池
  - 使用更高效的数据结构

### 1.3 内存优化技巧
**问题**：Android内存优化有哪些实用技巧？

**答案要点**：
- 图片优化：
  - 合适的图片格式（WebP、HEIF）
  - 图片压缩和缩放
  - 图片缓存策略
- 数据结构优化：
  - 使用SparseArray替代HashMap
  - 使用ArrayMap替代HashMap
  - 避免自动装箱
- 资源管理：
  - 及时释放资源
  - 使用try-with-resources
  - 避免大对象分配

## 2. 启动优化

### 2.1 冷启动与热启动
**问题**：冷启动和热启动的区别？如何优化冷启动？

**答案要点**：
- 冷启动：系统首次启动应用，需要创建进程
  - 过程：创建进程→初始化Application→启动Activity→显示界面
  - 耗时：2-3秒甚至更长
- 热启动：应用已存在进程，只是从后台切换到前台
  - 过程：从后台切换到前台→恢复Activity→显示界面
  - 耗时：几百毫秒
- 冷启动优化：
  - Application初始化优化
  - 首屏布局优化
  - 启动阶段异步加载非必要资源
  - 使用Theme.Splash避免白屏
  - 延迟初始化非关键组件

### 2.2 启动时间测量
**问题**：如何准确测量应用启动时间？

**答案要点**：
- 系统工具：
  - logcat中的ActivityManager日志
  - adb shell am start -W命令
  - Android Studio的Profiler
- 代码测量：
  - Application的onCreate时间戳
  - Activity的onCreate时间戳
  - 首帧渲染完成时间
- 关键指标：
  - 应用启动时间（Application到首Activity）
  - 首帧时间（Activity到首帧显示）
  - 完全可交互时间（首帧到可交互）

### 2.3 启动优化实践
**问题**：有哪些启动优化的最佳实践？

**答案要点**：
- 代码优化：
  - 减少Application初始化工作
  - 异步初始化非关键组件
  - 延迟加载非必要模块
- 资源优化：
  - 优化首屏资源
