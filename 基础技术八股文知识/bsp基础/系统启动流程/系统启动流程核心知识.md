# 系统启动流程核心知识

## 概述

Android系统启动流程是一个复杂的多阶段过程，从硬件上电到应用启动，涉及Bootloader、Linux内核、Android运行时等多个层次。理解系统启动流程对于系统优化、故障排查和定制开发至关重要。

### 启动阶段划分
1. **Bootloader阶段**：硬件初始化、引导加载
2. **Kernel阶段**：内核启动、驱动加载
3. **Init阶段**：系统服务初始化
4. **Zygote阶段**：应用进程孵化
5. **SystemServer阶段**：系统服务启动
6. **Launcher阶段**：用户界面启动

## 详细启动流程

### 1. Bootloader阶段

#### 主要工作
- **硬件初始化**：CPU、内存、时钟、外设等基础硬件初始化
- **引导加载**：加载内核镜像到内存
- **设备树解析**：解析硬件配置信息
- **安全验证**：验证内核和系统镜像的完整性

#### 关键组件
```c
// Bootloader的主要执行流程（伪代码）
void bootloader_main() {
    // 1. 最低限度的硬件初始化
    init_cpu();
    init_memory();
    init_clock();
    
    // 2. 加载设备树
    device_tree_t* dt = load_device_tree();
    
    // 3. 初始化关键外设
    init_serial_console();  // 串口调试
    init_storage();         // 存储设备
    init_display();         // 显示设备
    
    // 4. 加载内核
    kernel_image_t* kernel = load_kernel_from_storage();
    
    // 5. 设置启动参数
    boot_params_t params = {
        .kernel_addr = kernel->load_addr,
        .dtb_addr = dt->addr,
        .cmdline = "console=tty0 androidboot.hardware=generic"
    };
    
    // 6. 跳转到内核
    jump_to_kernel(¶ms);
}
```

### 2. Kernel阶段

#### 主要工作
- **内核初始化**：架构相关初始化、内存管理初始化
- **驱动加载**：设备驱动探测和初始化
- **进程管理**：创建init进程（PID 1）
- **文件系统**：挂载根文件系统

#### 内核启动流程
```c
// Linux内核启动流程（简化版）
start_kernel()
    → setup_arch()           # 架构相关初始化
    → setup_command_line()   # 解析启动参数
    → trap_init()           # 异常处理初始化
    → mm_init()             # 内存管理初始化
    → sched_init()          # 调度器初始化
    → time_init()           # 时间系统初始化
    → console_init()        # 控制台初始化
    → init_IRQ()            # 中断系统初始化
    → softirq_init()        # 软中断初始化
    → rest_init()           # 创建init进程
        → kernel_thread(kernel_init)  # 内核init线程
        → kernel_thread(kthreadd)     # 内核守护线程
```

#### Android内核特性
- **Binder驱动**：Android特有的IPC机制
- **Ashmem**：匿名共享内存
- **Logger**：系统日志驱动
- **Wakelock**：电源管理机制
- **Low Memory Killer**：内存不足时的进程回收

### 3. Init阶段

#### 主要工作
- **解析init.rc**：执行系统初始化脚本
- **启动守护进程**：启动系统关键服务
- **属性服务**：管理系统属性
- **SELinux初始化**：安全策略加载

#### init.rc解析流程
```bash
# init.rc示例片段
on early-init
    # 早期初始化
    start ueventd
    
on init
    # 主要初始化
    symlink /system/bin /bin
    mkdir /data 0771 system system
    
on boot
    # 启动系统服务
    class_start core
    class_start main
    
# 服务定义
service zygote /system/bin/app_process -Xzygote /system/bin --zygote --start-system-server
    class main
    socket zygote stream 660 root system
    onrestart write /sys/android_power/request_state wake
    onrestart write /sys/power/state on
    onrestart restart media
    onrestart restart netd
```

#### 属性服务（Property Service）
```c
// 属性服务的主要功能
void property_service_init() {
    // 初始化属性存储
    init_property_area();
    
    // 加载持久化属性
    load_persistent_properties();
    
    // 启动属性服务线程

// 属性设置流程
int property_set(const char* name, const char* value) {
    // 权限检查
    if (!check_permission(name)) {
        return -1;
    }
    
    // 属性更新
    update_property(name, value);
    
    // 触发属性变更事件
    property_changed(name, value);
    
    return 0;
}
```

### 4. Zygote阶段

#### 主要工作
- **预加载资源**：预加载类、资源、库文件
- **创建进程**：孵化应用进程
- **系统服务器启动**：启动SystemServer进程

#### Zygote启动流程
```java
// ZygoteInit.main()
public static void main(String[] argv) {
    // 1. 预加载资源
    preload();
    
    // 2. 启动SystemServer
    if (startSystemServer) {
        startSystemServer(abiList, socketName, zygoteServer);
    }
    
    // 3. 进入循环，监听连接请求
    zygoteServer.runSelectLoop(abiList);
    
    // 4. 关闭Zygote
    zygoteServer.closeServerSocket();
}

// 预加载过程
static void preload() {
    preloadClasses();      // 预加载常用类
    preloadResources();    // 预加载资源
    preloadOpenGL();       // 预加载OpenGL
    preloadSharedLibraries(); // 预加载共享库
}
```

### 5. SystemServer阶段

#### 主要工作
- **启动系统服务**：按顺序启动所有系统服务
- **服务依赖管理**：处理服务间的依赖关系
- **系统就绪通知**：通知系统启动完成

#### 系统服务启动顺序
```java
// SystemServer.main()
public static void main(String[] args) {
    new SystemServer().run();
}

private void run() {
    // 1. 准备主线程Looper
    Looper.prepareMainLooper();
    
    // 2. 加载动态库
    System.loadLibrary("android_servers");
    
    // 3. 启动引导服务
    startBootstrapServices();
    
    // 4. 启动核心服务
    startCoreServices();
    
    // 5. 启动其他服务
    startOtherServices();
    
    // 6. 启动完成
    Looper.loop();
}

// 引导服务启动
private void startBootstrapServices() {
    // Installer服务
    mInstaller = new Installer();
    mInstaller.start();
    
    // ActivityManagerService
    mActivityManagerService = mSystemServiceManager.startService(ActivityManagerService.class);
    mActivityManagerService.setSystemProcess();
    
    // PowerManagerService
    mPowerManagerService = mSystemServiceManager.startService(PowerManagerService.class);
    
    // PackageManagerService
    mPackageManagerService = PackageManagerService.main(...);
}
```

## 启动性能优化

### 关键性能指标
- **冷启动时间**：从按下电源键到Launcher显示的时间
- **系统服务启动时间**：各系统服务的启动耗时
- **应用启动时间**：首屏应用启动时间

### 优化策略
```java
// 启动优化示例：延迟初始化
public class LazyService {
    private volatile boolean mInitialized = false;
    
    public void initializeIfNeeded() {
        if (!mInitialized) {
            synchronized (this) {
                if (!mInitialized) {
                    // 延迟初始化逻辑
                    performHeavyInitialization();
                    mInitialized = true;
                }
            }
        }
    }
}
```
